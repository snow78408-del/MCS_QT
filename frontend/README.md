# frontend 模块

## 前端职责
前端是用户交互入口，负责：
- 参数输入
- 视频来源选择
- 初始化参数输入
- 运行状态展示
- 操作按钮触发（初始化、开始、暂停、继续、停止）
- 周期性读取 `orchestrator.get_snapshot()` 并刷新页面

## 前端不负责
前端不直接执行：
- 图像识别计算
- PID 反馈计算
- 泵硬件通信
- 串口命令下发与协议解析
- 控制循环调度

以上全部由后端 orchestrator 统一调度并对外提供接口。

## 目录结构
- `app.py`：兼容入口，导出 Qt 主窗口
- `qt_app.py`：PySide6 主窗口、页面、信号槽、线程池任务和状态轮询
- `config.py`：前端显示与刷新配置
- `vision_tuning.py`：识别算法分阶段调参工作台；后台执行检测，失败或超时自动回退到上次有效参数
- `vision_tuning_store.py`：在用户数据目录持久化调参页参数，并严格校验算法参数版本、字段和类型
- `pages/`
  - `parameter_page.py`：参数设定页面
  - `video_source_page.py`：视频来源选择页面
  - `init_page.py`：初始化参数页面
  - `monitor_page.py`：运行监控页面
  - `status_page.py`：状态详情页面
- `components/`
  - `status_panel.py`：系统状态面板
  - `pump_panel.py`：泵状态面板
  - `recognition_panel.py`：识别结果面板
  - `control_buttons.py`：控制按钮组件

## 页面功能
1. 参数设定页面
- 输入目标直径、像素转微米系数、控制周期
- 基础合法性校验
- 进入视频来源页面

2. 视频来源页面
- 选择实时摄像头或本地视频
- 摄像头编号/视频路径校验
- 进入初始化页面

3. 初始化页面
- 输入初始 `Q1/Q2`
- 调用 `configure() -> prepare_video() -> initialize_system()`
- 显示初始化状态

4. 监控页面
- 显示识别、泵状态、PID 控制结果、系统状态
- 提供开始/暂停/继续/停止按钮
- 停止实验后可将控制周期数据保存为 SQLite 数据库
- “导入数据”可只读加载已保存数据库，并按共同时间轴复现 Q1/Q2、液滴平均直径和平均速度曲线
- “更改目标”会弹出目标平均直径输入框；运行中确认后从下一控制周期采用新目标，可用于阶跃实验
- 保存并导入的数据以橙色虚线显示目标直径阶跃；泵曲线仍区分设备参数换算值和控制指令值
- 周期刷新快照

5. 状态页面
- 展示系统整体状态及原始快照视图

## 组件功能
1. `StatusPanel`
- 显示 `system_state/message/error`

2. `PumpPanel`
- 显示泵连接、通信、就绪状态、Q1/Q2、运行态、最近错误

3. `RecognitionPanel`
- 显示累计液滴总数，以及用户设定控制周期内的液滴数、平均直径、单胞率和有效性

4. `ControlButtons`
- 封装初始化/开始/暂停/继续/停止按钮
- 根据系统状态自动控制可点击性

## 与 orchestrator 交互方式
前端仅调用以下接口：
- `configure(system_config)`
- `prepare_video()`
- `initialize_system()`
- `start()`
- `pause()`
- `resume()`
- `stop()`
- `get_snapshot()`

## 刷新机制
- 监控页面和状态页面通过 `QTimer` 定时轮询
- 后端阻塞操作通过 `QThreadPool` 执行，结果由 Qt Signal 返回 GUI 线程
- 相机页执行多后端发现、设备选择、参数写入、测试取帧和参数回读
- 测试帧支持鼠标拖拽划选 ROI，并自动换算、保存原图比例坐标
- 相机操作分阶段写入轮转日志，界面可直接导出当前日志
- 泵机页先枚举串口候选，再以泵协议探测设备并提供全量读取与安全写入校验
- 监控视频使用 33 ms 精确定时器显示后端独立预览线程发布的原始帧，目标 30 FPS
- 状态信息由独立 QThread 等待每次 PID 控制结果后更新，不与视频绘制共用定时器
- 默认刷新间隔 `300ms`（可在 `config.py` 调整）
- 刷新过程只读快照，不阻塞主线程
- 后端耗时操作通过后台线程执行
- 算法调参刷新不占用 GUI 线程；非法参数会在运行前拦截，识别异常或超过 15 秒时保留上次成功画面并回退参数
- 首次启动会在用户数据目录的 `config/vision_tuning_parameters.json` 创建默认算法参数；之后启动自动读取，“保存参数”会原位替换该文件
- 算法升级导致 schema、字段、类型或取值不兼容时，启动会询问是否删除旧参数并重建默认文件；选择保留时本次仅使用内置默认值

## 用户操作流程
1. 参数设定
2. 视频来源选择
3. 初始化参数输入并初始化系统
4. 进入监控页面开始运行
5. 运行中可暂停/继续
6. 可随时停止并查看状态页面
