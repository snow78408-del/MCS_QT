# frontend 模块

## 前端职责
前端是用户交互入口，负责：
- 参数输入
- 视频来源选择
- 初始化参数输入
- 运行状态展示
- 操作按钮触发（初始化、开始、暂停、继续、停止）
- 周期性读取 `orchestrator.get_snapshot()` 并刷新页面

## 前端不负责
前端不直接执行：
- 图像识别计算
- PID 反馈计算
- 泵硬件通信
- 串口命令下发与协议解析
- 控制循环调度

以上全部由后端 orchestrator 统一调度并对外提供接口。

## 目录结构
- `app.py`：兼容入口，导出 Qt 主窗口
- `qt_app.py`：PySide6 主窗口、页面、信号槽、线程池任务和状态轮询
- `config.py`：前端显示与刷新配置
- `vision_tuning.py`：识别算法分阶段调参工作台；后台执行检测，失败或超时自动回退到上次有效参数
- `vision_tuning_store.py`：在用户数据目录持久化调参页参数，并严格校验算法参数版本、字段和类型
- `pages/`
  - `parameter_page.py`：参数设定页面
  - `video_source_page.py`：视频来源选择页面
  - `init_page.py`：初始化参数页面
  - `monitor_page.py`：运行监控页面
  - `status_page.py`：状态详情页面
- `components/`
  - `status_panel.py`：系统状态面板
  - `pump_panel.py`：泵状态面板
  - `recognition_panel.py`：识别结果面板
  - `control_buttons.py`：控制按钮组件

## 页面功能
1. 参数设定页面
- 使用带范围和单位的数值控件输入目标直径、光学参数和控制周期
- 实时显示预估比例、标定状态和下一步提示
- 运行监控页可打开非模态泵动力学标定窗口；本次相机验证和 Q1/Q2 写入回读通过后即可启动，无需人工进入初始化页，窗口会在后台准备视觉服务和安全运行环境，左侧监控视频持续刷新；标定按实际过线的有效液滴数量推进，不设固定实验时长，仅在视觉长期没有有效液滴时由安全看门狗停机；窗口显示进度、暂停/停止并由用户选择动力学标定 JSON 保存位置，原始阶跃测量另存为同目录审计文件
- 基础合法性校验后进入相机配置页面

2. 相机识别与读写页面
- 选择实时相机或本地视频，并按来源自动隐藏无关通信字段
- 按“来源与设备 → 参数测试 → ROI 划选”完成配置
- ROI、自动管道检定和已知宽度标定在独立高级设置窗口中分区显示；霍夫参数保留在测试帧区域
- 摄像头设备发现、参数写入、同步测试取帧和视频路径校验

3. 泵机识别与读写页面
- 扫描串口候选，验证泵协议并读取通道状态
- 使用带范围和单位的控件安全写入 Q1/Q2，并执行回读校验
- 写入回读成功后前往运行监控页启动泵动力学标定

4. 初始化页面
- 只读确认视频来源、ROI/标定、泵通信和初始 `Q1/Q2`，不在此页重复编辑泵参数
- 实时模式必须在本次程序启动中完成相机测试取帧和泵协议读取/回读校验；历史保存的设备 ID、串口和参数只显示为“仅保存配置”，不会冒充当前已连接
- 设备或相机参数变更后，本次验证状态立即失效；本地视频模式允许不连接泵
- 提供返回上一步修改配置和确认初始化两个明确操作
- 调用 `configure() -> prepare_video() -> initialize_system()`
- 显示初始化状态

5. 监控页面
- 无需先初始化即可进入查看状态、视频占位和调试入口；未初始化时真正的“开始”按钮保持禁用，硬件与 PID 安全前置条件不变
- 在实时视频旁打开非模态泵动力学标定窗口，并显示有效液滴采集数、阶跃进度和失败原因
- “上一周期识别帧”在每个有效塞状液滴框旁显示等效直径（μm），便于检查弯月面边界、轴向长度与数值是否一致
- 以关键指标摘要显示识别、泵状态、PID 控制结果和系统状态，完整文本按需展开
- 运行控制、实验工具和数据操作分组显示；暂停/继续合并为状态按钮，停止和安全锁使用独立警示样式
- 停止实验后可将控制周期数据保存为 SQLite 数据库
- “导入数据”可只读加载已保存数据库；泵1/Q1 与泵2/Q2 使用独立纵轴图表并突出流速变化点，液滴平均直径和平均速度按共同时间轴复现
- “更改目标”会弹出目标平均直径输入框；运行中确认后从下一控制周期采用新目标，可用于阶跃实验
- 保存并导入的数据以橙色虚线显示目标直径阶跃；泵曲线仍区分设备参数换算值和控制指令值
- 周期刷新快照

6. 状态页面
- 通过系统、视频源、识别、泵机和 PID 健康卡片展示关键状态
- 默认隐藏原始快照 JSON，并提供展开、复制和导出操作

7. 算法调参页面
- 使用生成区本地视频或图像，按“中心采样带 → 轴向强度/边缘峰 → 弯月面配对 → 等效直径”分阶段调参，不连接相机和泵机
- 页面从基础参数同步当前 `μm/px`，确保用户填写的通道尺寸所对应的像素门限与实时识别一致；H/W/κV 仍由相机/ROI 标定维护，不能用图像阈值调参覆盖
- 可调项包括中心带比例、边缘 MAD 倍数、最小峰距、塞长/管宽范围、相内外对比、二维弯月面支撑和液滴亮暗极性
- 点击“保存参数”后，参数文件会被替换，并立即通过 orchestrator 应用到实时生成区识别；从下一采样帧生效，不重启泵、PID，也不清空累计计数

主导航将前五项归为“实验流程”，将状态和调参归为“工具与诊断”；流程项会显示完成、进行中、异常或锁定状态。导航收起后保留页面图标和悬浮说明。

## 组件功能
1. `StatusPanel`
- 显示 `system_state/message/error`

2. `PumpPanel`
- 显示泵连接、通信、就绪状态、Q1/Q2、运行态、最近错误

3. `RecognitionPanel`
- 显示累计液滴总数，以及用户设定控制周期内的液滴数、平均直径、单胞率和有效性

4. `ControlButtons`
- 封装初始化/开始/暂停/继续/停止按钮
- 根据系统状态自动控制可点击性

## 与 orchestrator 交互方式
前端仅调用以下接口：
- `configure(system_config)`
- `prepare_video()`
- `initialize_system()`
- `start()`
- `pause()`
- `resume()`
- `stop()`
- `get_snapshot()`
- `apply_vision_tuning(detector_config, channel_region_config)`

## 刷新机制
- 监控页面和状态页面通过 `QTimer` 定时轮询
- 后端阻塞操作通过 `QThreadPool` 执行，结果由 Qt Signal 返回 GUI 线程
- 相机页执行多后端发现、设备选择、参数写入、测试取帧和参数回读
- 测试帧支持鼠标拖拽划选 ROI，并自动换算、保存原图比例坐标
- 已知高度标定按“用户当前输入的框选区域实际高度 ÷ 两条内壁像素间距”计算 μm/px，液滴直径统一使用该比例换算
- 泵芯片标定的每个试验先恢复并回读统一 Q1/Q2 基准，再分别执行单通道或联合阶跃；基线和响应均达到配置的有效液滴观察数后才判定稳定，避免前一阶跃串扰和瞬态平台误判
- 相机操作分阶段写入轮转日志，界面可直接导出当前日志
- 泵机页先枚举串口候选，再以泵协议探测设备并提供全量读取与安全写入校验
- 监控视频使用 33 ms 精确定时器显示后端独立预览线程发布的原始帧，目标 30 FPS
- 状态信息由独立 QThread 等待每次 PID 控制结果后更新，不与视频绘制共用定时器
- 默认刷新间隔 `300ms`（可在 `config.py` 调整）
- 刷新过程只读快照，不阻塞主线程
- 后端耗时操作通过后台线程执行
- 算法调参预览与实时检测共同调用生成区塞状液滴检测器；刷新不占用 GUI 线程，非法参数会在运行前拦截，识别异常或超过 15 秒时保留上次成功画面并回退参数
- 首次启动会在用户数据目录的 `config/vision_tuning_parameters.json` 创建默认算法参数；之后启动自动读取并应用到采样识别，“保存参数”会原位替换该文件并立即更新实时检测器
- 算法升级导致 schema、字段、类型或取值不兼容时，启动会询问是否删除旧参数并重建默认文件；选择保留时本次仅使用内置默认值

## 用户操作流程
1. 参数设定
2. 视频来源选择
3. 在初始化确认页核对配置并初始化系统
4. 进入监控页面开始运行
5. 运行中可暂停/继续
6. 可随时停止并查看状态页面
