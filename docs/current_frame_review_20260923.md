# 当前帧定位复核

`tools/capture_detector_review.py` 不再读取保存的管壁坐标用于裁剪。每个被测帧先进入
`ParallelWallLocalizer`，通过当前帧与邻帧证据校验后才扶正、检测。定位失败输出
`not_measured`、具体原因和完整定位证据，`selected=null`，不能解释为零液柱。

离线样本必须提供原录像、`sample_index.json` 和 `frames.ndjson`。每个样本使用前二十三帧
加自身，使用实际采集时间，且校验视频目标帧与抽样 PNG 逐像素一致。孤立图片不冒充
连续帧。输出 `localized_report.json`；只有定位通过才输出 `localized_roi_*` 和
`localized_overlay_*`。检测结果仅为像素诊断，不凭名义管宽声明物理标尺有效。

运行示例：

```powershell
.venv\Scripts\python.exe tools/capture_detector_review.py --output output/v1-b1-20260923/fifteen_point_review --video output/v1-b1-20260923/raw_frames.mkv
```
