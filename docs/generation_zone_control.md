# 生成区液滴识别与 Q1/Q2 闭环

正式运行的测量区域为液滴生成区。通道截面 `H×W` 必须按当前芯片由用户填写，50、60、70 仅为常见示例，任何有限正数（包括用户重新填写的 430）都可作为当前尺寸。旧 schema 中缺少生成区 H/W 字段的 430 μm 才会从当前计算中移出，并保存在 `previous_channel_width_um`；当前 H/W 始终取用户这次应用的生成区尺寸。下游观察区圆检测仅保留为历史算法兼容模式，不再向实时 PID 提供直径。

## 图像测量

图像先按两条管壁摆正并锁定实时比例 `s=W_user/W_px`，其中 `W_user` 是用户填写的当前芯片内宽。识别器对管道中心带取横向中位数剖面，以中位数和 MAD 建立自适应弯月面阈值；只有同时满足前后边缘强度、二维边缘支撑、内部/外部相位对比、完整入镜以及 `2.5 min(H,W) <= L <= 12 min(H,W)` 的配对才登记为 C 区塞状液滴。

方形/矩形通道内长液滴的体积采用：

```text
A_eff = H W - (4-pi) (2/H + 2/W)^(-2)
V      = kappa_V A_eff (L - W/3)
d_eq   = (6 V / pi)^(1/3)
```

其中 `L` 是生成区塞长，`d_eq` 是送入 PID 的等效球径，`kappa_V` 是独立体积参照得到的修正系数；没有参照时保持 1.0，并在标定记录中明确固化。检测器不读取 PID 目标作为尺寸门限，修改目标不会改变识别结果。

每个完整液滴穿过虚拟计数线时只锁定一次等效直径。生成频率采用相邻过线时间间隔中位数的倒数，平移速度采用连续帧轨迹位移和采集时间戳的中位数。频率和速度用于显示及质量诊断，当前闭环只有平均等效直径一个目标。

## 图像参数调试

主界面的“液滴算法调参”与实时监控调用同一个 `generation_plug` 检测器。预览从基础参数同步当前 `μm/px`，所以管宽像素值、塞长范围和等效直径不会再使用旧比例。建议依次调节：

1. 先调整中心采样带，使其避开两侧管壁但覆盖稳定的相内强度。
2. 调整边缘 MAD 倍数和最小峰距，使每个真实弯月面只留下一个峰。
3. 再调塞长范围、相内外对比、二维支撑比例和亮暗极性，排除管壁、杂质及共享边缘造成的假配对。
4. 最后逐帧检查矩形液滴框、轴向长度和等效直径；不能用修改 `kappa_V` 来补偿漏检或边缘定位错误。

保存只更新图像判据并从下一采样帧生效，不重启泵/PID，不清空累计计数，也不覆盖相机页维护的 `H/W/kappa_V` 物理标定。

## 采样建议

- 相机帧率至少满足 `F_s >= 8 f_max`；当前约 30 Hz 的成滴频率建议使用 240 fps 左右，101.6 fps 可用于调试但每滴帧数偏少。
- 通过硬件 ROI 只保留生成通道和断裂后的完整液滴段，优先提高帧率而不是保留无关画面。
- 运动模糊建议限制在 2 px 内，即 `t_exp <= 2/v_px`；当前样片建议从 100–300 μs 曝光开始调试。
- 控制和标定均使用硬件帧号/时间戳；预览刷新与识别采样分离。
- 每个基线和阶跃至少使用 30 个全新液滴；正常建议 50 个。30 个是允许判定的下限，不是未稳定时的硬停止数。

## 新标定流程

1. 标定生成区管宽，锁定本次运行的实时 `μm/px`。
2. 输入并固化 `H`、`W` 和 `kappa_V`，确认生成区识别能稳定输出塞长和等效直径。
3. 在安全 C 区工作点依次执行 `基线 -> Q1+ -> 基线 -> Q1- -> 基线 -> Q2+ -> 基线 -> Q2-`，每次试验间必须恢复同一基线并重新判稳。
4. 由正负配对阶跃计算 `g_j = d(ln d)/d(ln Q_j)`。稳定但低于视觉阈值的通道记为合法弱通道并以零灵敏度退出分配；显著响应方向不一致时标定失败。
5. 沿已识别方向执行联合正负阶跃，验证组合方向，识别端到端延迟 `tau` 和一阶时间常数 `T`。
6. 使用全部联合阶跃曲线拟合 FOPDT，并执行不同幅值的独立验证阶跃。
7. 保存 schema v3 生成区标定；只有 `validated_for_pi=true` 才能授权实时 PI。旧 schema v1/v2 记录仅供审计。

## PID 与双泵分配

控制误差为：

```text
e = ln(d_target / d_mean)
u = Kp e + Ki integral(e dt), Kd = 0
```

Q1/Q2 分配由实测灵敏度决定：

```text
delta_log_Q = g / (g^T g + lambda) * u
delta_Q_j   ~= Q_j,base * delta_log_Q_j
```

因此方向和比例不再使用旧的 `Q1:-2 / Q2:+1` 常数。PI 初值按识别的一阶滞后模型保守计算：

```text
lambda_c = max(2.5 tau, 2 tau)
Kp       = T / (lambda_c + tau)
Ti       = min(T, 4(lambda_c + tau))
Ki       = Kp / Ti
```

所有泵命令仍受局部标定包络、单周期变化、总流量和 `Q1>Q2` 硬件约束。没有有效生成区动力学映射时，实时 PID 在启动相机和泵之前直接拒绝；弱通道可以退出，但两个通道都弱或任一有效通道方向矛盾时不得放行。
