# 弱轮廓液滴识别复核

用户授权连接相机后，通过项目海康适配器采集两批各 40 帧，读取设备当前参数，
不修改曝光、流量或用户 ROI，不连接泵；每批采集结束均停止取流并释放设备。

当前保存的两条管壁长度不同，取共同区间后得到 33×316 像素 ROI。
因此画面边缘经常只有部分液滴，这些不能作为完整尺寸样本。此修改未扩大 ROI，
也未改变物理尺度。更大视野的识别需要用户重新框选两条有效管壁。

原横向强度范围容易被固定亮管壁主导，弱胶囊被分裂；默认 12 灰度级原始对比
阈值也会拒绝肉眼可见的弱轮廓。仅降低阈值无法解决连续相间隙误判。

新增上下肩部与中心强度差的符号一致性分段：上下对比同向时支持胶囊，
相反时支持间隙。只有两种相位都有明确证据才启用，其他画面保持旧路径。
该路径按原始噪声设置不低于 3 灰度级的对比下限，保留两侧背景及二维轮廓验证。
距离边界不足四分之一通道宽度的端点标记为残滴，防止噪声导致边缘伪闭合。

第一批回放原算法输出 0 个完整实例；修改后逐帧输出 11 个。
第二批独立采集逐帧输出 10 个。逐帧目视检查这两批叠加图，
输出框对应完整胶囊，未见间隙或残滴被计入。
这是 80 帧的有限样本复核，实例数不是跨帧去重后的液滴总数，也不是全工况准确率。

本地证据位于 output/live-detector-20260918 和
output/live-detector-20260918-validation，包含原图、ROI、叠加图及 report.json。
自动测试另覆盖弱不对称轮廓、亮暗反转、竖直流向，以及既有的背景纹理、
密集液滴、部分入镜和相邻液滴背景隔离情形。
