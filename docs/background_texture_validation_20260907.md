# 背景纹理误检修正：离线验证

## 修改与适用范围

生成区检测增加原图轮廓对比检查，比较候选主体与左右背景的横向剖面，避免固定管壁与亮度纹理仅凭增强后边缘被接受。门限默认 12 个 8 位灰度级，可在调参页调整。原长度、轮廓覆盖与尺寸换算条件保留，不增加时间等待。

连续计数启动校准另要求两相对比变化范围至少 12 灰度级；保持原 32 帧窗口，背景闪烁不足以建立可信两相时不输出有效频率。此改动没有连接相机或泵，也没有改写用户保存的 ROI、曝光、物理标定或调参文件。

## 同条件检测器对照

基线为提交 `00685d5` 的检测器；修正前后使用相同帧、原保存生成区检测参数、1.725 μm/px 配置以及各自指定的管壁。物理比例没有在此次回放中重新标定。表中是跨帧检测实例数，不能视为独立液滴总数。

正样本全部 63 帧的检测长度与基线一致。其参考管壁沿用此前回放的 `(0,310)→(590,320)` 与 `(0,345)→(590,355)`。本片临时管壁为 `(0,268)→(720,312)` 与 `(0,342)→(720,386)`，只是图像检查范围，没有写入应用配置。

另用完整离线尺寸管线、保存的 H/W/体积修正参数复跑背景片，两套 ROI 均为 0 尺寸候选。该路径的旧候选总数与上表不同，因为运行时会用已保存物理几何覆盖检测器默认几何，不能混为同一条件对比。

背景片临时 ROI 的连续计数内部事件由 5 次降为 0；频率仍报告无效。正样本连续过线事件仍为 8 次，零起始帧号为 36、39、43、46、50、53、56、60，与之前记录一致。

## 速度与局限

交替运行前后检测器的一次离线对照中，保存 ROI 平均 13.62→14.27 ms/帧，临时 ROI 为 17.13→17.65 ms/帧，正样本为 10.98→11.93 ms/帧。仅包括检测器计算，不含解码、GUI、相机和泵通信；此结果不是实时性能保证。未新增 sleep、固定等待或额外帧缓存。

背景片约 1.58 秒，短于保存的 10 秒控制窗口，因此不产生完整控制窗口。零检测说明该片中复现的候选被拒绝，不能证明任意新场景都没有误检，也不能单凭此片确认不存在低对比真实液滴。此次正样本是开发回放，并非独立人工尺寸真值集。

执行 `.venv\Scripts\python.exe -m pytest -q --tb=short`：352 passed，6 subtests passed。
