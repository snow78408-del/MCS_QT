# 三项卷积离线验证

本次实现全部为离线工具，没有连接相机或泵，没有更改生产测量、反馈资格或停止路径。
各块管壁坐标保留独立；芯片尺寸和像素标尺未知时不填默认物理尺寸。

## 端点候选

`tools/convolution_endpoints.py` 使用三个尺度的一维高斯导数提议正负边缘对，
与现有相位候选及“只保留获得梯度支持的原候选”一起比较。
候选支持不会将外侧端点换成内部强梯度，也不会绕过原相位检查。

60张已有标注图、159个液滴中，原规则匹配154个、无未匹配候选；
三个梯度尺度分别匹配121/129/139个，产生79/85/26个未匹配候选。
梯度长度误差中位数约49%–51%，明显差于原规则9.21%。支持过滤保留126个，
因此两类方案都不替换现有规则。另完成五日期539张未标注原图回放，候选数不当作准确率。
这是校准集结果，不是独立测试；之前的高斯平滑对比见 [卷积预处理](convolution_audit.md)。

## 视野质量

`tools/convolution_geometry.py` 固定每块前10秒参考，比较上下壁、左右半段的
卷积梯度模板。独立记录位移、壁距、倾角、相关性和能量变化；不自动更新参考。
默认平移/壁距/倾角变化阈值均为3传感器px，相关性0.65、最低能量比0.35；
这些是可通过 `GeometrySettings` 单独配置的工程参数，不是物理定律。

用过去5个1 Hz帧的因果中位图，每5秒评分：SA/SB/F1/F2的117个可评分位置中，
分别89/115/115/1个与参考一致。F2仍大量不确定：早段与后段亮暗结构明显变化，
模板出现约2–4px偏移及显著能量变化；无法仅凭此区分真实壁移动和流态/光照改变。
不得将提示解释为F2没有液滴，或自动把不确定状态写成确定缺壁标签。

R1/R2由用户现场缺壁信息排除，不能计为自动检测成功。5个原本一致的真实图像样本，
经四类故障注入共20次均被拦截；这是配对诊断，不是现场检出率。
离线 `QualityGate` 验证重复身份、中断、连续3次无效后提示和恢复；
未接入真实生命周期的冻结/停泵。正式接入前仍需核实实体参考及人工异常标签。

## 因果时间卷积

`tools/convolution_dynamics.py` 使用分段常数脉冲响应的积分表示阶跃响应，
分界0/10/30/60/120/240/360秒。过去各次Q2对数变化的影响累加，未来事件不影响过去。
360秒之后响应保持末值，不凭空假设更长期动力学。多事件叠加通过合成测试；
现有合格实测块各只有一次孤立Q2变化，不能宣称已经实测验证频繁调节。

开发比较只用3个合格孤立Q2正向变化块，按整块/整日期隔离；FIR正则强度在训练块
内部选择，只有一个训练组时固定0.01。与保持、事前趋势、衰减趋势、一阶模型比较。
同日期同起始状态停启曲线作为单独诊断，不跨日期强行共享，不声称无偏因果扣除。
整日期留出时连该日期的停启结果也不参与训练/修正。加入停启修正并未一致改善结果。

仅用10/16一个历史块训练，冻结同一模型，回顾性评分10/23主几何5Hz/10秒箱：

|块|保持RMSE|事前趋势RMSE|一阶RMSE|FIR RMSE|
|---|---:|---:|---:|---:|
|F1|3.975|2.007|1.439|1.109|
|F2|3.576|2.150|1.887|1.655|

单位均为条带px。FIR相对保持改善72.1%/53.7%，相对趋势改善44.7%/23.0%。
±1px几何变体也单列保存；这不涵盖实际壁距、倾角和视野移动的不确定性。
历史训练使用1Hz口径，本次评分使用5Hz主箱口径，二者在输出中分开。
这些是探索性正向预测收益，既非事前验证，也不构成正反动态或MPC资格。

10/23采用记录的命令回读相对观测起点时间代理，保留请求时间；
较早缺细分时序的记录使用观测零点，明确未知实际起效时刻。回读不是芯片流动传感器。
不重建记录前未知输入，不假定停泵即流体归零。冻结模型哈希与预测哈希分开记录。

## 复现

参数均为显式输入路径，输出必须为新目录；模型和标注输出不可作为现场授权文件。

```powershell
.venv/Scripts/python.exe tools/convolution_endpoints.py --labels tests/fixtures/user_phase_calibration/labels.json --manifest <source_manifest.json> --samples <卷积预处理输出/sampled_rows.json> --output <新目录/endpoints>
.venv/Scripts/python.exe tools/convolution_geometry.py --manifest <source_manifest.json> --output <新目录/geometry_causal>
.venv/Scripts/python.exe tools/convolution_dynamics.py --dataset <cross_date_1hz_curated.json> --primary <primary_5hz_curated.json> --inventory <completed_six_block_inventory.json> --output <新目录/dynamics_frozen>
```

可选报告依赖安装：`.venv/Scripts/python.exe -m pip install -e ".[offline-analysis]"`。
然后运行 `tools/report_convolution_extensions.py --root <新目录> --manifest <source_manifest.json> --output <新报告目录>`，
输出报告、预测曲线和原图几何复核图。报告核验两个主评分使用同一冻结模型。

定向测试27项通过；最终完整回归1361项、6个子测试通过（103.57秒）。
测试涵盖强梯度与外缘分离、冻结参考、合成平移/倾斜/缺壁、陈旧帧、连续无效、
时间卷积因果性、正反事件叠加、整块泄漏拒绝和“改变留出后段不改变预测”。
人工标注质量、真实异常准确率与闭环收益未被这些软件测试证明。
