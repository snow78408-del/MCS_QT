# 密集液滴背景参照修正：2026-09-16

## 问题与修改

`raw_outline_contrast` 原先在候选两侧固定取约 0.3 倍图像高度的窗口。液滴间隙较小时，窗口会包含下一滴的轮廓，主体减背景的对比随之降低，两个独立候选都可能被过滤。

现在由检测器提供相邻包络之间的背景边界，采样窗口取固定窗口与该范围的交集。边缘残滴和长度不合格的候选仍限制邻滴的背景窗口。左右参照仍分别至少需要两列像素，且保留 12 灰度级门限、轮廓覆盖检查和物理尺寸换算。没有改动连续计数、跟踪、线程或用户保存参数。

`raw_outline_contrast` 新增可选关键字 `background_start`、`background_stop`，分别表示背景允许范围的起点和不包含的终点，默认整幅图，兼容既有调用。

## 结论与限制

本次修复的是已经分离出两个候选、但背景窗口混入邻滴造成的漏检。原视频结果保持一致，不能宣称该视频召回率已经提高，更不能将跨帧实例数当作独立液滴数或准确率。

更窄的间隙可能在包络阶段就被合并，本修改不解决此问题；没有足够背景列的分离候选继续拒绝。通用弱对比恢复、多帧补检和生成区独立人工真值评测仍需另行验证。
