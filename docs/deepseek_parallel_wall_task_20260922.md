# DeepSeek 下一步执行：平行管壁定位、扶正和采集接入

本任务承接 `deepseek_review_round2_20260922.md`，由DeepSeek实现、Codex独立审核。用户已明确生成区是平行管道，优先使用这一几何约束。此次只进行离线实现与无硬件测试，不启动泵、相机，也不执行旧现场脚本。继续遵守AGENTS.md及项目虚拟环境要求。

## 1. 本次要完成的行为

对包含生成区的原始画面，自动定位目标直管段的一对平行内壁，判断定位证据是否足够，将其扶正后测量完整液柱。相机平移或小角度旋转后应重新定位，而不是复用昨天坐标。定位、物理标尺、芯片深度三种证据分别管理：定位成功不意味着物理尺寸已标定。

## 2. 复用现有代码但不要混淆各自用途

- `channel_calibration.detect_wall_line_candidates()` 已提供全图长边候选及真实端点，可复用候选生成。
- 当前 `_full_frame_parallel_pair()` 以旧间距±40%筛选并取最长线对，仅是带先验核验，不是自动定位完整方案。失去旧位置时必须支持无旧坐标重新获取；未知间距不能偷偷用默认50µm反推。
- `channel_region.detect_channel_region()` 已有多帧区域统计，但它聚合的是高空间频率区域，不等同于跟踪固定内壁，也不证明区域内亮边就是管壁。可作辅助区域证据，不能直接冒充内壁标签。

## 3. 定位流程及输出

1. 在原始分辨率或有明确可逆坐标映射的工作图中生成长边候选；保留候选端点、支持边缘、有效可见长度和图像坐标空间。
2. 使用法向距离而不是垂直y差计算两壁间距。候选对须有足够公共轴向范围、近似平行、沿公共区间间距一致。只在共见范围内评估，不能将短边任意外推至全图。
3. 限定目标为生成区下游的直管测量段；支路、交汇口和弯曲段不强行拟合为平行管。图中若有多条同样可信的管道，必须报告候选竞争，不按最长线静默选中其他通道。
4. 跨帧关联候选线对，统计中线、方向和间距的稳定性、出现比例及分段边缘支持。采用有容量和时间上限的缓冲；不能在GUI线程阻塞等待，不能引入无界队列。
5. 用管内移动界面与静止壁边的差异作辅助证据，不把“多帧不动”作为真管壁充分条件：停泵液柱、静止气泡、固定纹理也不动。重复相同帧不能增加独立支持数；没有有效运动或图像对比不足时允许输出待确认。
6. 沿实际测量段多个位置核验上下壁及内部液柱覆盖，使用实际四边形和两壁方程，不能只用中心点加外接矩形判断覆盖。
7. 唯一可信线对才能生成扶正变换。歧义、截断、单壁、低对比或证据过期时，返回明确拒绝理由，禁止落回旧ROI继续输出有效尺寸。

输出至少包含：定位状态、原因、目标直管范围、原图两壁端点、候选与竞争分数、支持帧号及时间范围、间距/方向/位置分布、沿程覆盖证据、坐标变换和几何版本。阈值集中配置并记录来源；数值需要离线样本支持，不为了通过昨天24张图随意放宽。

## 4. 必修的接入边界

- 修复适配器把 `duct_depth_um=None` 替换为DetectorConfig默认深度的行为。没有明确芯片深度来源只输出长度；不能把默认值包装成declared_chip_geometry。
- 相机或图像尺寸、视场、变换、管道定位发生变化时，旧几何与标尺验证状态按各自适用范围失效，不能沿用一个永久validated布尔值。
- 新测量路径的拒绝结果必须控制本次实验写出的尺寸列和稳态样本，不能只放进诊断字典而让旧尺寸照常参与标定。
- 保留已有旧脚本原始证据，建立可安全导入、默认离线、复用orchestrator接口的采集入口。测量输入只来自对应原始帧包，禁止frame_jpeg预览检测回退。
- 检查共享detector调用和配置更新的锁；新增多帧定位的生命周期要覆盖暂停、停止、清空及重新定位。

## 5. 验收样本与测试

| 场景 | 必须验证的行为 |
| --- | --- |
| 平行管道整体平移、旋转、分辨率改变 | 自动重新定位，坐标正确映回原图；相同场景尺寸差异满足明确容差 |
| 管壁固定、内部液柱移动 | 优先锁定完整壁边，不能随液柱亮边漂移 |
| 停泵液柱、只有静态图或重复帧 | 不伪造运动证据或多帧独立支持；证据不足有明确状态 |
| 两条管道、多组长平行纹理 | 返回正确目标证据或歧义，不能仅因线长而接受 |
| 两壁中心对齐但端部裁掉液柱 | 沿程覆盖拒绝，不允许中心点检查放行 |
| 单壁、交汇口、弯道、出画、低对比 | 不产生错误的有效直管尺寸 |
| 未声明深度、未验证标尺 | 分别拒绝等效体积尺寸、物理单位，保留适用像素诊断 |
| 定位后突然平移、旧定位帧、新采集帧错配 | 旧证据失效，重新获取期间明确无效 |
| 配置更新/停止与测量并发 | 无数据混用、死锁和残留帧，设备测试用桩 |

补充从实际离线采集入口到CSV再到稳态分析的端到端测试。所有输入图像与时间来源在测试中明确，合成图只证明软件行为，不证明物理精度。

昨日A/B共24张原始图可用于失效回归；它们是停泵标定帧，不能用作动态区分壁边和液柱的充分证据。已裁剪JPEG预览不能恢复被裁掉的壁面。缺少合适真实动态片段时提交缺口，不编造实际验证完成。
