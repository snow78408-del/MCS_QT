# 控制优化路线（2026-09-08）

本文记录当前批次控制及后续设计建议。已实现独立基线等待、PID 采集／分析帧数设置和批次调度；频率闭环、模糊 PID 和 MPC 尚未实现。

## 1. 按帧批次的异步 PID

本项目此处的异步定义为：先采集 N 帧，再分析末尾连续 M 帧，汇总该批尺寸后执行一次 PID 决策，最后按需要调泵。默认 N=M=5，也可设置 10/10、15/10 等。预览与独立频率计数继续运行，控制批次之间不积压尺寸计算任务。

- 每批带真实采集起止时间、质量、运行代次和唯一批次编号，拒绝过期或重复样本。
- orchestrator 保持唯一执行权；全部分析完成后才进入 PID，决定／事务完成后才允许下一批，不排队执行旧命令。
- PID 候选状态仅在事务成功且运行代次有效时提交；暂停、停止、故障使在途结果失效，保留现有安全停机和通信仲裁。
- 界面显示采集和分析帧数及批次进度。继续遵守现有 1200 波特率下 7.5 秒循环间隔下限；解除限制前必须重新测量通信耗时和泵／芯片响应。
- 优先以自适应 PI 为基准，仅在数据证明有收益时启用滤波微分。增益更新慢于反馈、限制变化幅度；无有效测量、输出饱和或响应未到达时冻结自适应。
- 模糊 PID 作为替代增益调度策略，以归一化误差和误差变化率输出有界增益修正，不与自适应算法同时改写增益。通过同一批回放比较后再决定采用哪个。

异步只能改善软件等待与数据新鲜度，不能消除泵和芯片的物理延迟。当前反馈门控要求调整后的完整稳定窗口；若要在瞬态期间继续控制，需要另外验证带延迟补偿的控制策略。

## 2. 频率／尺寸二选一

将控制目标建模为 `diameter_um` 或 `frequency_hz`，一次只激活一个。测量可以同时展示两项，但目标、误差单位、质量门控、控制器历史、标定和数据库记录都必须对应所选项。

尺寸沿用生成区等效直径。频率使用连续过线计数和真实时间窗，避免使用抽样帧中的可见液滴数。低频时窗口应覆盖足够事件；真实零频率必须与失帧、识别失败区分，不能把无数据当作零误差输入。

分别辨识 Q1/Q2 对尺寸和频率的局部灵敏度与时延。总流量和流量比可以作为候选控制坐标，但影响方向和耦合强度需实测，不能预设为完全解耦。两种目标使用各自归一化增益和执行器分配参数，不能直接复用直径 PID 系数。

首版仅允许停止后切换控制目标，并重新检查对应标定。后续再实现运行中无扰切换：保持当前流量作为工作点，清理积分、微分和旧测量窗口。

## 3. MPC 在测量和辨识之后

先做局部线性、双输入单输出的约束 MPC，输出由所选目标决定。尺寸可从已有通过独立验证的 FOPDT 标定起步；频率需要新增对应辨识。模型显式处理输入延迟和保持时间，预测时域覆盖主要响应过程。

代价函数组合归一化跟踪误差、调流增量和偏离工作点的惩罚，约束复用 Q1/Q2 上下限及变化率。不要让 MPC 与 PID 同时持有执行权。求解设置截止时间；超时、不可行或模型残差过大时保持安全输出或切回经验证的 PI，并使用统一事务接口。

先以影子模式预测和记录，不下发 MPC 命令；对独立阶跃和扰动数据检查多步误差，再进行受控闭环比较。MPC 基于有限时域预测并显式处理约束的基本方法可参考 [do-mpc 官方理论文档](https://www.do-mpc.com/en/latest/theory_mpc.html)。这里的线性模型和分阶段实现顺序是本项目的设计建议。

## 4. 验收顺序

1. 固定测量配置，复核误检、漏检、尺寸偏差、频率偏差和测量时间戳；记录算法参数版本，防止把调参造成的读数变化误认为控制改善。
2. 用相同初始条件、目标阶跃和扰动比较固定 PI、自适应 PID、模糊 PID、MPC，分别统计误差积分、超调、调节时间、稳态误差、尺寸 CV、调流次数及饱和时间。
3. 模拟旧帧、乱序、掉帧、串口超时、第二路写入失败、暂停/停止期间返回结果，确认没有重复调流或迟到状态提交。
4. 分目标、分工况报告独立验证结果；先完成无硬件回放，再做受控设备实验。
