# 70/20→60/20有界响应实验

新芯片可在`geometry_guard.reference_patch_px`声明当前图像中的静态参照矩形
`[x,y,width,height]`（传感器像素）。自定义矩形须完整位于图内、宽高至少20px、
且不与已声明通道相交；无纹理参照拒绝注册。未声明时沿用原参照矩形。
准备时可用高曝光核对管壁位置，随后恢复正式曝光，确认视野未移动，并保存正式设置下
的静态参照；运行中仍保留0.85相关门槛、±2px漂移限制与原异常停机路径。

`tools/run_q1_response.py --plan <file>`默认无设备预检，加`--live`才运行。使用项目`.venv`。这是固定单次Q1降流实验，不授权追加其他流量点。

复用已有相机独立读取线程、设备锁、原图有界写入、耗液累计、STOP文件及异常清理、停泵确认。第一阶段在70/20下建立基准，在120/180/240秒检查两分钟的中心、带宽和趋势；相邻两次通过才允许目标，最早180秒。几何通过相同芯片上一轮的管外静态特征注册到本轮启动前原图；相关不足或位移过大时拒绝启动。

数值筛选采用固定标尺下直径相对指标等价的立方根长度，不把未知μm标尺填入门控。缺测不补零；没有形态或端点真值认证，数值通过不能被引用为绝对测量验收。原图须持续人工复核，异常时STOP。

run01发生视野移动后，新增运行中静态特征检查：每最多2秒检查最新1Hz原图，单轴位移超过2px或模板相关低于0.85即通过既有异常清理停泵，geometry_guard.json保留最后证据。在线基准计算移到有15秒超时的独立Python进程，采集进程持续读相机，计算前后仍检查几何；避免主进程Python计算与采集争用。此检查针对平移，不能替代旋转、形态和端点验收。

检查图像来自采集线程每0.5秒更新的单个有界内存快照，使用已有短锁交接；不读取写入线程正在替换的latest.png，避免Windows文件共享冲突。超过2秒未更新或启动后无快照即失败；仅停泵预检查首次取帧前允许使用已保存pre_start图像。

240秒尚不合格则正常清理停泵，不进入目标。目标540秒预留及30秒事务、10μL余量需同时满足油水当前累计上限。每针上限最多900μL，新满针确认另记；指令阶段按旧较高70.5/20.5累计，读回确认60/20后才改为60.5/20.5累计。这是命令行程预算，不是实际芯片流量测量。

run05启用另一个明确限定的时间安排：baseline_check_s=[120,180,240,300,360,420]、target_duration_s=300。基准仍要求连续两次通过，最长7分钟；目标5分钟不自动宣称达到稳态。按最长平台和30秒事务、10μL余量计算油841.25μL，水266.25μL，留有在线计算及启动余量；实际切换前后仍重新检查累计预算。仅支持此安排及原240/540安排，拒绝任意放大时间。run05预测使用目标0–120秒训练，180–300秒未来验证，在验证开始前冻结，和旧轮180秒训练/360–540秒验证分别保存。

run06使用显式fixed_diagnostic策略：baseline_policy=fixed_diagnostic、baseline_duration_s=120、baseline_check_s=[120]、target_duration_s=300。这是固定120s参考后的一次Q1诊断响应，统计稳态只在离线加标签，未评估/未通过不伪装成qualified_numeric=true。原qualified策略不变，未知策略一律拒绝。单针预算包括70.5×2+60.5×5+70.5×0.5+10=488.75μL油，水163.75μL，加实际启动累计；切换前后重新核验。几何、采集、队列、余量、事务读回及安全停泵仍强制执行，诊断模式不授权正式MPC控制。固定参考阶段不运行在线稳态计算，全部真实切换时间单独记录。

用户随后明确要求每段5分钟：run06在停泵预检查阶段收到STOP，未写参数/启动泵，不耗液。run07允许匹配的baseline_duration_s=300、baseline_check_s=[300]，target仍300秒。油预算70.5×5+60.5×5+70.5×0.5+10=700.25μL，水225.25μL（不含实际启动累计）。固定诊断仅允许120/300或300/300两种安排，其他时长或检查时刻不匹配均拒绝。

运行中流量更新必须有停止确认、写入读回、重启确认；事务失败不得进入目标阶段，所有异常复用既有最终停泵流程。基准及目标各有独立时间原点，切换全速原图单列transition，不能混为稳态样本。目标结束后不继续返回或追加平台。

采样：基准前30秒及120秒之后100fps保存，目标前60秒及420–450秒100fps保存，其余20fps。流态变坏、图像无效、写入失败、超时或预算触限均安全结束；未覆盖完整响应如实报告。

测试：`-m pytest tests/test_q1_response.py tests/test_constant_observation.py tests/test_a_first_three_capture.py -q`，以及完整pytest。测试不连接设备，覆盖波动稳态与漂移区别、缺测、预算准入、无资格不调流、事务失败和单次更新证据。
