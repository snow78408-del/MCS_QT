# 液滴尺寸 MPC

## 使用

参数页的“反馈控制器”可选择 **MPC 液滴尺寸预测控制**，保存并重新初始化后生效。
默认仍为原 PI/PID。API 对应 `SystemConfig(feedback_controller="MPC", ...)`。
实时闭环沿用像素标定、生成区测量、泵检查和生命周期授权流程。

MPC 需要 schema-v3 正式动力学标定且 `validated_for_mpc=True`；只有
`.mpc-training.json`、PI 合格但 MPC 不合格的记录或旧版标定均不能启用。
训练数据和拟合资格是模型证据，不能代替新控制器的实际设备验证。
加载模型不会连接设备；启动和泵指令继续由 orchestrator 管理。

安装依赖和无硬件验证（Windows）：

```powershell
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m pytest tests/test_mpc_controller.py tests/test_mpc_integration.py
.venv/Scripts/python.exe -m pytest
```

运行状态显示控制模式、预测时域、末端预测尺寸及偏差估计。
`PIDCommand` / `ControlSnapshot` 的 `mpc_prediction_um` 保存完整十步预测；
`mpc_horizon_s` 是预测时域秒数，`mpc_offset_um` 是尺寸偏差估计。
保留既有命令数据结构和事务日志，`control_owner="MPC"` 标明实际控制器。
MPC 不叠加旧 PID 前馈，界面在该模式下禁用两个前馈勾选框。

## 论文方法与本机适配

参考 Vicente Martínez 等的 *Dynamic modeling and predictive control of a
microfluidic system*，采用有限时域预测、控制增量惩罚、线性约束和滚动执行。
论文原版 DOI：[10.4995/riai.2024.19953](https://doi.org/10.4995/riai.2024.19953)。
原论文输入为三路压力、输出为流量；本机输入为两路注射泵流量设定
Q1/Q2（uL/min），输出为视觉等效球直径（μm）。泵参数回读不是独立物理流量测量。

控制器使用已有生成区标定的二次响应曲面，或局部对数尺寸模型；在当前
Q1/Q2 处求导，得到本次优化的线性模型。动态部分使用已辨识的一阶惯性和延迟：

`D_ss(Q) = 标定稳态模型(Q)`

`s(t) = 0 (t <= delay)，否则 1 - exp(-(t-delay)/tau)`

未来尺寸由当前测量、稳态预测以及每个流量增量的阶跃响应叠加得到。
每次优化最小化归一化尺寸误差平方和与归一化流量增量平方和。
SciPy SLSQP 使用解析目标梯度求解该凸二次问题；最多 100 次迭代，
求解成功后再次检查整条计划的有限性和可行性，只执行第一组 Q1/Q2。
下一次取得合格测量后重新线性化和优化。

输出偏差由标量随机游走 Kalman 更新估计，以补偿缓慢漂移。其输入只允许
通过现有响应后窗口门控的测量；它不是原论文的 13 状态流体观测器。
偏差超过标定基准直径的 25% 时冻结并提示重新标定。

## 约束和时间

- 10 步预测、10 步控制；增量权重默认 0.1，均先做量纲归一化。
- 整条计划满足控制配置与标定范围的交集、Q1/Q2 最小间隔、总流量上限和单次变化上限。
- 线性化范围限制在当前点周围各标定流量跨度的 20% 内；BO 移交后再与 BO 局部权限相交。
- 无可行解、求解未收敛、重复帧、无效测量或模型数值异常时保持当前流量；关键流量无效时要求停泵。
- 控制状态先在副本中计算，只有双通道事务完成并且生命周期仍有效才提交；失败、取消、暂停、停止不提交候选状态。
- 预测步长取配置周期与 `保守延迟 + 3 × (tau + tau不确定性)` 的较大值。
  保留 7.5–30 秒配置周期、现有响应等待和完整采样窗口门控。
  实际命令间隔还受串口事务和采样耗时影响，不能把预测步长当成保证执行周期。

## 验证边界

回归测试覆盖合成闭环阶跃和恒定偏差、线性与二次模型、整条预测轨迹约束、
求解失败、BO 移交、配置/界面传递，以及泵事务成功、失败、暂停、停止时的状态提交。
这些测试不接相机或串口，不证明真实设备上 MPC 已优于 PI。
当前实现以响应后窗口为反馈基础；高频瞬态 MPC 还需要准确的命令生效时间、
输入延迟历史和更密集的有效尺寸测量，不能直接套用论文的 0.1 秒采样率。
