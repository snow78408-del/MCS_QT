# 人工粗边界监督的液滴识别候选

2026-10-22新增 `backend.vision.learned_phase.LearnedPhaseProposer`，接受已经注册的灰度通道条带，采用轻量一维卷积网络学习沿流向的主体/间隙及边界。24个横向采样位置作为输入通道，不使用日期、流量、位置标签或人工端点作为推理输入。

2026-10-22 Codex更新：生产规则已增加同相位峰合并和有界光学尾部收紧；学习网络现在仅记录影子诊断，不修改测量或尺寸历史。最新规则结果见 [直接优化报告](droplet_direct_optimization_20261022.md)。

历史实验有两种口径，不可混用：

1. **独立学习候选**（`predict()`，早期离线比较）：网络直接输出主体区间，可补出原规则未接受的滴。留出集 44/44、端点约 5.33 px，但会新增原算法拒绝的候选，**不是当前保留原算法的一对一修正模式**。
2. **原算法＋有界修正**（`refine()` → 检测器入口 `refine_existing_intervals`，历史离线实验）：原 `calibrated_phase_intervals` 的候选数量与物相决定不变，学习模型只对 IoU≥0.6 的一对一可靠匹配做端点修正；无法匹配、大偏移或载相侧曲率不符时保留原端点。留出集与原规则同为 40/44，端点 6.84→6.65 px、长度 9.51→8.87 px（`pipeline_metrics.json` 口径）。

当前默认只运行改进后的原规则。显式注入 phase_refiner 时，模式 2 的受限建议仅写入 phase_diagnostics.learned_endpoint_refinement，mode=shadow。

本轮人工标注包含82张原图上的自由画笔边界；相邻笔画推定为左右端点，不当作逐像素分割真值。按日期与实验块隔离为54张训练、16张验证、12张测试。邻近重复笔画合并；1张仍有奇数边界，只用于边界辅助监督，不参与主体区间评价。未标注外部区域不自动标负类。几何沿用历史注册，评估的是相同几何条件下识别主体的改进，不是自动定位管壁的评价。

网络不默认接入 `DropletDetector` 在线测量或控制。当前权重明确 `production_authorized=False`；返回值不证明细颈已断开、不提供经过标尺认证的绝对尺寸。学习模块不改变生产规则的测量输出。

`production_authorized=False` 是模型元数据，不作为隔离的唯一依据。检测器把原图和候选的副本交给模型，随后将建议和有界修正写入独立诊断，主候选、有效测量、尺寸历史、跟踪与统计继续使用规则结果。模型默认不加载。历史训练数据和权重保存在用户数据目录 `experiments/droplet_learning_20261022/`。

## 离线调用

PyTorch为可选依赖，仅在构建/加载模型时导入。本轮使用项目虚拟环境中的 `torch 2.14.1+cpu`；主应用不因新增模块强制安装PyTorch。按需安装CPU版本：

```powershell
.venv/Scripts/python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/Scripts/python.exe tools/replay_learned_phase.py --model <learned_phase.pt> --image <原图.png或.npy> --geometry <geometry.json> --output <新结果.json>
```

geometry包含四个原图像素坐标角点 `quad`（左上、右上、右下、左下）和条带尺寸 `nx`、`ny`。几何必须在原图内且为非退化凸四边形。入口不连接设备，输出拒绝覆盖。规则候选支撑阈值仍为0.02；通过原守卫后，以0.03支撑作有界收紧。显式更强的原支撑阈值不会被降低。

## 已验证范围

12张留出图、人工标记区域内44个完整液滴（按轴向区间 IoU≥0.5 匹配），分两个口径报告：

- **原规则**：40 个匹配、0 误报、4 漏检，端点 6.84 px、长度 9.51 px。
- **独立学习候选（旧，已不再作为当前接点）**：44 个匹配、0 误报，端点约 5.33 px、长度约 6.82 px。它补出 4 个原规则未接受的滴，不能拿这个召回率配上原算法的低耗时。
- **原算法＋有界修正（历史接点，`pipeline_metrics.json`）**：仍 40 个匹配、0 误报、4 漏检（不增删候选），端点 6.65 px、长度 8.87 px。端点改善约 2.8%、长度改善约 6.8%，均未达任务书 10% 的验收线，故本轮保留影子候选、不默认切换。

三者不是同一评价口径，不得混用。以上不是总体 100% 准确率：样本小且按敏感性挑样，仍缺少足量气泡、细丝、空视场和新成像条件下的独立真实负例。

原始网络在均匀背景上出现误报，因此推理保留原规则的相差对比度下限15灰度、边缘余量与1–4倍通道跨度长度限制。合成空白、纯黑、噪声、连续液柱返回空列表；这些探针不能替代真实负例验收。没有为了匹配粗画笔而弱化现有硬件或控制授权。

本次只训练一次，并用验证集选轮次和概率阈值。留出集只评价，不用于选择模型权重；负例探针后增加的守卫是已有规则的约束移植，未依据留出标签调门槛。
