## 必须整改

### R1 [P1] “影子”只是注释，修正结果实际进入有效测量与状态历史

位置：`backend/vision/pipeline.py:66`的声明，以及`backend/vision/detector.py:475`、`:502`、`:595`的真实路径。

注入refiner后，`transverse_selected`被修正结果替换，随后写入`_phase_length_history`，计算`equivalent_diameters_px`并保持`diameter_valid=True`；pipeline再把这些结果传给跟踪和统计。默认None避免了当前自动启用，但并不构成注入后的影子隔离，也没有由模型`production_authorized=False`强制限制该数据流。

独立复现：同一合成三滴图，原长度[92,86,86]，向内1像素的refiner后为[90,84,84]；直径随之变化，两者有效标记均为[true,true,true]，历史分别记录原值和修正值。新增`test_refiner_does_not_change_diameter_valid`恰好允许此问题，不能作为影子隔离证据。

要求：显式分离影子建议与主测量输出/历史，影子模式下主结果、跟踪输入和控制统计必须与无模型一致；将学习建议、受限修正、差异及拒绝理由单独记录。若保留离线“应用修正”实验模式，应显式限制该模式的测量控制资格，不能靠注释或手工约定隔离。补测试验证数值与状态历史，不只比较布尔标记。默认原流程保持不变。

### R2 [P2] D阶段没有执行，现有连续数据并非不存在

交付benchmark为每一张图新建VisionPipeline并固定timestamp=1.0，因此没有连续跟踪、尺寸历史演化或真实帧间隔验证。报告第6节将缺失归因于没有带真实帧号/时间戳的连续片段，与本机资料不符。

独立检查：`E:/MCS_QT_Data/experiments/experiment_20261016/B_Q2_20261016_run01/frame_manifest.ndjson`共28560条，其中B1_70_20存在**3001帧连续硬件帧号序列**，跨度30.0009886秒，主机单调间隔中位0.0100006秒，全部对应原图文件存在。这不等于已经验收其图像与计时物理含义，但足以启动离线时序验证。

要求：先检查片段事件/几何、帧缺口和时钟，再按原顺序、实际单调时间持续复用pipeline回放；分段重置，不跨实验块复用跟踪状态。交付逐帧缺失/拒绝/计数及耗时，可靠关联时才评价同一对象的长度波动。无额外人工真值可明确暂不评动态准确率，不能据此省略回放。首次使用的片段不能偷偷加入训练集。

### R3 [P2] 计时证据不能支撑P95目标“通过”

报告第7节把“无学习P95下降≥20%”列通过，但比较使用的是未保存不可变产物的旧5.77ms；本轮冻结基线已包含之前的提速，不能据此归因本轮成果。

`stage_timing.py:71–109`把WARMUP=1的那一轮也加入统计，且`full_pipeline_replica`从已扶正、外带已算好的图开始计时，实际不含这两段。它直接调用detector/tracker/metrics且未执行生产pipeline当前观测元数据对齐，不能称全链副本。独立组件计时不包含完整检测器有界修正成本，因此`model.refine()`的P95并不等于新增全链开销。`per_frame_metrics.csv`仅保存三次的median/min/max，未保存每次原始时间。

要求：冻结基线与新实现交替测量，预热排除，至少三轮单独保存；保留frame_id/repeat_id/各段耗时原始数据；对照必须使用同一流水线。分开报告模型前向、完整修正阶段和全链耗时，墙线估计缺失注明N/A。修正“通过”为未证实，直到可复现证据满足目标。

### R4 [P2] 最差误差单位及匹配口径错误

`analyze_blocks.py`按中心包含关系重新配对，并在0–719归一化轴坐标直接计算长度差，没有乘 `(nx-1)/719`，却在报告中写成px。V2_060的57.5689是归一化轴单位；用主评测相同IoU匹配和像素换算，实际为**35.1499条带像素**，仍是失败例，但数值不能混用。按uid汇总得到的是阶段，不等同于日期＋实验块的独立分组。

要求：复用主评测的一对一IoU匹配，保留匹配ID，统一坐标和单位；比较原/改进的共同匹配集合，而不是仅以TP数量相等推定是同一集合。按真实日期＋block汇总，另列阶段。重生成最差例排序、叠图和报告，标注重绘线与原始人工笔迹的区别。
