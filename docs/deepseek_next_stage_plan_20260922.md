## 阶段一：只修完三处稳态时间问题

对象：`backend/orchestrator/offline_campaign.py::analyse_steady()`。Codex反例在 `output/codex_r4_probe.py`，结果在 `output/codex-r4-probe-results.txt`。复跑请另存输出，不覆盖审核证据。

### A. 每个窗口的新鲜度必须只看该窗口之前的数据

现实现使用全阶段 `last_accepted_s` 判断早期窗口是否新鲜，未来恢复的数据会让过去缺失窗口通过。

已复现：0–300秒每秒一条常量80，130–140秒全部拒绝，141秒后恢复；140秒窗口仍 fresh=true、确认于140秒，但其最后有效点在129秒，距窗口终点11秒，超过5秒新鲜度门槛。

修复：每个检查时刻只使用截至该时刻的数据，按实际样本时间判新鲜度，不能用未来点，也不要用取整的桶时间替代采样时间。窗口覆盖率、最大空档和新鲜度分别记录。补一个离线前缀一致性检查：在同一检查时刻，完整记录的结果必须与截断到该时刻的记录一致。

### B. 区分曾经确认稳定与当前仍然稳定

已复现：0–160秒恒定80，之后按0.5单位/秒持续上升；结果仍status=ok、confirmed_s=140，虽另有later_violation=true，摘要容易被当作当前稳态。

修复：保留首次确认历史，明确输出当前窗口状态和失稳原因。区分未确认、当前稳定、确认后失稳、确认后数据陈旧、覆盖不足等状态。若后面重新稳定，给出新确认时间，不能沿用首次确认时间代表最终持续稳定。

继续采用现有工程口径作为可配置默认：120秒窗口、10秒检查、连续三次通过、|斜率|≤0.1；这是此前助手采用的工程阈值，用户明确接受过−0.073的小漂移，不要改回0.01且分布跨度≤2的旧双门槛。覆盖率0.6、最大空档15秒、新鲜度5秒也是当前软件配置，不称物理标定结果。分布宽度单独报告。

### C. 指令开始和回读完成不可混为一谈

已复现：只有readback_completed_monotonic=1000，没有command_started_monotonic，也输出command_to_steady_s=140。

修复：分别输出 command_to_confirmation_s、readback_to_confirmation_s；缺少对应时间就留空。只有观测帧时间时输出 observation_to_confirmation_s，并标明不能用于泵指令响应时间。保留时间零点、时间来源和确认时刻绝对单调时钟值。验证命令/回读的先后、一致性、有限性；同档时间记录互相冲突时拒绝该推导。

统一措辞：窗口确认时间不是物理时间常数，也不是已辨识的液滴开始响应时刻。三个连续检查有重叠，不能当三次独立实验。

## 阶段二：准备短时验证，先离线交付

准备一个可审核的短时采集计划与入口，不实际采集。基准Q1:Q2=70:20。计划在液路充满且画面可见液柱后记录约60–120秒完整原始动态片段；该时长是验证检测链的计划值，不是达到稳态的结论。排气/充液段单独标记，不纳入正式响应拟合。

短时采集需要：

1. 独立标尺证据：相同成像配置下的标尺原图、像素区间、物理长度和来源。若只有通道宽度假设，不能直接标成独立校准。
2. 芯片深度显式值与来源；未知深度只输出轴向长度，不补默认值。
3. 原始帧、硬件帧号、采集时间及时间来源；保存图像变换、管壁候选、选择/拒绝理由、标尺适用范围。估算实际存储开销并设容量/时长上限。
4. 设备就绪、剩余油水、允许工况、可用行程及停机边界记录表。字段未知就列为待现场填写，不猜测。程序必须可停止、异常可保留已采数据，设备操作有超时及停机确认路径。
5. 挑选至少10个不同时间点提供原图、壁线、扶正图、液柱两端和计算尺寸对照。边界模糊或人工也无法判别时标无效，不把算法自身输出当真值。

短时验证通过条件：测量区完整包含目标直管及液柱；真实检测器能在动态画面持续给出可复核轮廓；像素/物理单位和帧时序一致；缺失或拒绝如实记录。定位成功率、人工对照差异和无效原因实际报告，不预先编造已达到的精度。

若未通过，依据这段真实数据解决具体问题；不开始5分钟长驻留网格。没有真实动态视频仍是显式缺口。

## 阶段三：短时验证通过后的正式实验计划（此次只准备）

固定Q2=20，以70:20为返回基准：

| 轮次 | 建议顺序 |
| --- | --- |
| 1 | 70:20 → 50:20 → 70:20 → 80:20 → 70:20 |
| 2 | 70:20 → 60:20 → 70:20 → 90:20 → 70:20 |
| 3 | 70:20 → 90:20 → 70:20 → 60:20 → 70:20 |
| 4 | 70:20 → 80:20 → 70:20 → 50:20 → 70:20 |

每档计划至少5分钟；达到时间不自动等于稳态。若仍不稳，只在预先填写的液量、行程与最长驻留边界内延长；达到边界标未稳定并按计划收尾，不无限运行。下一次阶跃前先确认返回基准是否恢复；补液或成像变化后新建批次，重新建立基准，不拼成连续阶跃。

以上20段最低共100分钟；仅按命令值估算，Q1累计7.00mL、Q2累计2.00mL，不包含充液、排气、延长、切换或损耗。这是预算，绝非实测流量。正式安排需依据实际剩余液量拆分，不能因序列写好就连续运行。

Q1扫描有可信结果后，再固定Q1=70改变Q2。具体Q2点由现场允许范围和有效成滴区间决定，本轮不猜上下限。若研究“比值本身”而非固定Q2下的综合变化，还需要相同比值不同总流量的对照；否则比值与总流量影响不可分离。

每次阶跃保存完整指令前基线、指令开始、回读完成、持续图像及尺寸记录。指令执行期间不能停止记录而遗漏响应起点；若有空档必须明确标出。
