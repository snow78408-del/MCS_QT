# Codex 第三轮审核：尚有可复现误判，暂不进入正式标定

本轮仅离线读取、检查证据、运行测试与独立反例；没有操作设备。默认深度回退已在实现中移除，显式来源与矩形截面路径保留；新增候选定位、拒绝闸门及离线入口有实质进展。以下反例不能用既有测试全部通过替代。

## P1：最新帧无管道，旧几何仍被标成最新帧的已定位结果

`parallel_walls.py::_localize_locked()` 根据历史最佳簇生成结果，却把最新观测的frame_id写入geometry；最新帧不在该簇、甚至没有任何线对，也没有禁止localized。

独立复现：三帧合成移动液柱得到localized，再送入全黑帧103。仍返回localized、frame_id=103，但支持帧号仅[100,101,102]。这不是合法的“当前帧定位证据”，会绕过下游定位帧与测量帧相等的检查。

返工：历史几何可保留为先验，当前帧必须有对应位置/覆盖/质量确认才能输出可用定位；无候选、换视场、平移或遮挡时返回丢失/待确认。旧支持证据不得改写帧号冒充新证据。增加当前空白帧、全遮挡、突然换另一通道的回归，并断言CSV accepted=false。

## P1：亮度变化被当成流动

`assess_motion()` 用管内绝对灰度差超过噪声阈值作为内容运动，但没有消除全局亮度变化。对绝对帧差计算MAD，在整幅加常数时MAD接近0，全部管内点都被判显著变化。

独立复现：一张没有液柱、没有位移的静态合成直管图，连续整体加0、10、20灰阶；最终localized、motion.available=true、changed_fraction=1，wall_change与interior_change同为10。这证明“位置稳定且内部像素改变”不足以证明流动。

返工：对照管外背景和壁带，抑制照明/曝光偏置与增益变化；需要空间位移/流向一致性等可区分证据。纯亮度漂移、全局闪烁、局部光斑变化和静态噪声必须不能认证流动。避免写“只有比例判据才对噪声免疫”这类未经证明的断言。沿轴运动的长边也可能是图像伪影，不能仅靠端点变化断定是液柱。

## P1：稀疏数据和陈旧数据仍可被判为稳态

`offline_campaign.py::analyse_steady()` 只要求总跨度覆盖120秒，窗口内三个时间桶即可参与检查，没有有效秒覆盖率、最大间隔或末端新鲜度要求。

独立构造t=0、40、80、120秒四条accepted尺寸80µm，结果status=ok、slope_limit_met=true、confirmed_check_index=10。三个检查实际共享稀疏旧点，不能证明连续120秒稳定。

返工：从所有行建立完整阶段及结束时间；全拒绝阶段不能消失。检查每个真实时间窗的覆盖、最大空档、最新有效帧时间，拒绝长缺失窗口。最近有效样本后持续拒绝时不能仍以旧样本末时刻报告当前稳定。输出首次/持续通过的实际时间与时间零点，不仅是索引；当前start_s未使用，command_started/readback字段亦未进入分析。没有指令时间只能报告观察窗确认，不能输出泵指令到稳态时间。补稀疏、末段失效、全部拒绝、乱序/重复时间及命令空档测试。

## P2：离线配置声明的深度未传入测量

CampaignConfig.duct_depth_um仅写入summary，run_campaign调用measure_generation_zone时未传此值或其来源。因此文档示例把50写入配置并不实际声明到测量链；vision对象若持有别的深度，summary与计算可能不一致。

返工：定义唯一配置来源。将值/来源/证据状态实际传递并核对，或删除误导字段要求从公开服务配置声明；冲突必须拒绝。测试config=100与vision=50以及config=None的行为，确保输出元数据对应实际计算。

## P2：无硬件端到端正路径仍使用检测器桩

tests/test_offline_campaign.py明确用_StubDetector固定返回柱塞长度。它证明数据传递，但不能证明真实定位器+真实检测器能共同处理一段图像。单模块各自通过不能代替组合正路径。

返工：至少补一个真实定位器、真实DropletDetector、真实适配器、CSV与稳态分析共同工作的离线正路径；只有设备使用桩。真实动态片段不存在仍要如实注明，合成正路径也不能称物理验证完成。

## 后续接入前还需处理

- packet_stream()会先将整个输入转tuple，run_campaign把所有行留内存并在结束后才写盘。目前可称有限离线回放，不能直接作为长期现场流式入口。后续现场接入要求有界缓冲、增量写盘、异常保留已采数据及独立安全停止路径。
- 帧包目前没有原始尺寸/预处理来源的可验证契约；没有frame_jpeg参数不等于能检测任意传入数组是否预览图。文档应写明调用者保证与程序校验的边界。
- 新快照闸门覆盖frame_diameters/avg与质量标志，但raw_frame_diameters、crossed_track_diameters及校准过线缓存仍取旧路径。上线前逐一确认消费者，防止旧标定数据混入；不要概括声称所有尺寸列都已切换。
