# 固定次数非线性自动标定

## 实验和模型

默认每个建模重复包含 Q1±、Q2±、Q1-/Q2+ 及其反向，共 6 次。
独立验证使用同一组合的较小幅值正反阶跃，每个验证重复 2 次。
合计 6R+2V，运行中不追加轮次，不放大阶跃；通信、样本超时或停止仍可中止。
响应符号、单次响应阈值不再决定是否继续预定采集。

将实际回读流量在工作点中心化并按实验幅值缩放，得到 x1、x2。
拟合 f = b1*x1 + b2*x2 + b11*x1² + b12*x1*x2 + b22*x2²。
每次测量使用 Δd = f(Q_after)-f(Q_baseline)，每个试验等权，
基线偏移不直接当作阶跃响应；未消除的持续漂移仍会表现为拟合或验证误差。
正反阶跃同号可以由平方项解释，不预设两个泵的物理作用方向。
秩和条件数用于检查能否独立辨识五个系数，不按残差删除试验。

各试验的原始动态曲线用于共享一阶惯性加延迟拟合，单次 onset 标记不筛除曲线。
这是有限工作区间的经验模型，不能代表任意流态、任意历史下的系统。
独立验证不参与静态系数、动态参数或工作点选择。

## PID 与 MPC

在基准工作点对响应面求偏导，换算为对数尺寸/流量增益，
沿用已有 PI 分配、抗饱和、变化率和安全停机链路。
系数标准误用于识别不确定的局部方向；平方项及交互项限制局部 PID 包络。
局部斜率为零、信息不足或验证不通过时不会伪造可用的 PID 参数。
这是局部固定参数 PI（Kd=0），不是已实现全范围增益调度的非线性控制器。

通过验证后，正式记录含 nonlinear_model，保存应用流程保持不变。
MPC 数据包保留回读/命令流量、时间序列、训练/验证分组、单位、模型及资格标记。
PID 未通过或实验中止也导出不可加载为控制标定的 MPC 数据包，
并标记 complete_collection、失败原因和未完成试验。
建模数据可用于另行辨识更复杂模型，不等于已经部署 MPC。

## 论文依据与边界

Crawford、Smith、Whyte（2017，Scientific Reports，DOI 10.1038/s41598-017-11254-5）
展示图像测量反馈、装置相关的控制参数整定及压力泵的动态表现；
其中压力增益和时间尺度不能直接套用于本系统的注射泵。

Cubaud、Mason（2008，Physics of Fluids 20，053302）的第 VI.B 节、式 (4)
给出滴落区长度与体积分数/毛细数的分段幂律，明确有几何、流态和黏度比边界。
论文的 Q1/Q2 相定义也不能直接等同于本项目泵编号。
这里采用数据辨识二次响应面，不硬编码该论文的经验系数，
也不将论文的塞长 d 直接当成本项目等效球径。
