# 有界70/20恒流原图观察

`tools/run_constant_observation.py --plan <session_plan.json>`默认只进行无设备预检，显式加`--live`才连接泵与相机。使用项目`.venv`的Python。

入口只允许单一70/20、60–720秒观察；不能自动切换到50/20或追加点。继承已验证的设备锁、原始帧身份、独立相机读取线程、参数回读、启动确认、异常/停止清理和停泵确认。当前初始参数不满足既有安全流量比时拒绝启动，不绕过原校验。

保存原始Mono8 PNG：全程20Hz选择实际到达帧，观察0–30、180–210、540–570秒保存全部相机帧。每输入帧最多保存一次，不补造漏采时刻。10秒停泵存储试采及30秒停泵指令前记录单列，不能当作流动基准。

输出`frame_manifest.ndjson`、原图、`live_status.json`、逐事务命令及会话摘要；既有STOP文件、相机超时、存储错误和耗液上限触发正常安全停止。原图不应用旧芯片壁线。`latest.png`用于观察，原图端点及当前壁距另行审核。

计划需要本次补液/可用量记录，单针保守累计上限不超过900μL，并覆盖30秒启动预算。预算按70.5/20.5μL/min计时，不是独立流量测量，实际针筒余量仍需现场确认。无效或重复帧、写入队列溢出均不能默默忽略。

该入口仅执行有界记录，不实时宣布统计稳态或验证压力机理；人工/离线每60秒复核并可通过STOP结束。最长时间完成也不等于测量或稳态验收。输出等效直径前仍须绑定当前50μm内壁尺度和50×50体积近似，不使用计划中的像素占位值换算物理长度。

无设备测试：`.venv/Scripts/python.exe -m pytest tests/test_constant_observation.py tests/test_a_first_three_capture.py -q`。完整回归另按AGENTS要求执行。
