## 4. 应撤回的结论

**A. 由本批分析提出、现予撤回的**

1. **"泵只输送指令的 5–6%，差 16 倍"** → 撤回为条件情景。它同时依赖相别、截面、速度分支、k、φ。
2. **"PID/MPC 增益应乘 0.061 / 会大 16 倍振荡"** → 撤回。
   对象增益与控制器增益不是同一个量：若标定输入本来就是命令流量，`r` 已经包含在辨识出的对象增益里，
   再乘一次是重复计数。**在核对模型输入定义与整定方法前不得据此调参。**
3. **"改 `syringe_code` 会让流量瞬间 ×16"** → 降级为**待验证风险提示**，不作为任何操作依据。
4. **"CH1 必然是分散相"** → 撤回为未定。
5. **"两段录像互相独立验证了模型"** → 撤回。0.75% 的一致性建立在硬编码的流量、速度分支、长度、
   截面之上，再用同一组数据选 k≈1.4 回代，**不构成独立验证**，也未传播输入误差。
6. **"k ≤ 2.096 是本两相系统的硬上界"** → 撤回。那是**单相**方管中心线/平均速度比。
   受限长液滴可以低于平均流速，不能仅凭 k<1 排除 CH2
   （Jakieła 等，µTAS 2011）。
7. **"0.049 ≤ r ≤ 0.070 是实测区间"** → 撤回为条件区间，其中 φ≥0.7 是俯视假设。
8. **"30–35 s 到稳态"与"必须等 10 分钟"** → 两条都不成立。稳定时间应由观测判据确定，
   现有数据不足以给出固定值，长录本身也没有稳定平台。
9. **"生成率 98–158 Hz"** → 撤回为条件区间（依赖相别、截面、r、k）。

**B. 我自己在 09-19 这批材料里犯的错误（逐条认领）**

| # | 错误 | 现在的值 / 状态 |
| --- | --- | --- |
| 1 | §10.2 把 `g` 随 Q1 的变化方向写反：称 50→70 时 g 从 0.06995 升到 0.0979 | **0.049967**（g ∝ 1/q）。且该论证本身不成立：不能用"对上模型"反推历史流量 |
| 2 | §4 去混叠换算 | `131.7 − 101.6 = 30.1 Hz`，与记录的 31.7 Hz 不符 |
| 3 | §4 模糊式多写 `× 174` | 按所写算式是 1013.57 px；去掉才是 5.825 px；判据本身还需曝光/光学证据 |
| 4 | 在 §9.2/§10 之间混用 L = 107 px、120 px、105 px | 三者口径不同（单帧目视 / 长录前 300 帧检测器 / 参考检测器），**不得混用**；120 与 107 差 12%，不是 2% |
| 5 | 闭合计算把**长录前 300 帧**的长度统计与**末端**速度配对 | 同一时段几何未验证，该配对作废 |
| 6 | 描述长录"146 个点单调无跳变" | 与同一份日志的 `[STATS] sign changes 10 / rel std 48.5%` 直接冲突 |
| 7 | 池的位置一处写"下游"、一处写"生成区→池→观测窗" | 未核对芯片流路，撤回该结构断言 |
| 8 | "所有物理量随 s 线性缩放" | 长度 ∝ s；仅在三维均按同一标尺缩放时，体积及相应流量 ∝ s³，比例约 0.809。独立固定截面时需重新传播误差 |
| 9 | "一分钟输送 1000 µL 验推杆行程" | 按 70 µL/min 单路需 **14.29 min**，步骤不成立，须按实际行程/容量/停机条件重设计 |
| 10 | 把两个近似体积公式互相接近当成体积正确 | 只证明两个模型接近，不是体积精度验证 |
