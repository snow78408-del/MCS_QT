# 液滴工艺优化预实验第二版：先确认优化评价是否被暂态误导

日期：2026-09-22。交付范围：方案修订，无设备操作、无产品代码修改。替代第一版的优先执行顺序，不撤销已验收的离线功能。

## 1. 为什么调整

第一版优先覆盖范围，尚不足以区分液路阶跃、长时间漂移、同值串口写入影响与不同起点的记忆效应。参数点更多不一定更有辨识力。

现有120秒窗口、每10秒三次通过最早在140秒确认，这是算法时间下限；旧200–261秒同样受起检门槛与测量问题影响。它们不应成为新算法必须学习的物理稳定时间标签。

0.1µm/s工程斜率门槛若对应持续线性漂移，120秒可漂移12µm；用户接受过的0.073µm/s也可累计约8.76µm。接受小斜率与足以比较工艺优劣是两个要求。旧工程判据继续记录，但不单独决定优化评价可靠性，也不擅自改回旧0.01门槛。

## 2. 研究问题重新定义

主问题：在给定允许评价误差时，从调泵到能够可靠评价这一工艺点需要多久？

三个输出分别是：
1. 持续变化开始的可辨识区间；
2. 原工程判据的确认时间；
3. 给定误差容许范围下的可靠评价时间。

主实验不承诺一定能观察到排名翻转。先检验早期与末段评价的偏差及其可重复性；不同参数效果可区分且目标已冻结后，才进行选点/排名验证。不能事后挑目标使排名翻转。

## 3. 已有证据与前提

近期其他任务的最终结论见`offline_stage_acceptance_20260922.md`、`deepseek_measurement_audit_plan_20260921.md`和`output/steady_curve_20260922/`图表。离线记录和计算阶段通过，真实尺寸、动态帧记录和停止链仍待现场验证。旧曲线有保留价值但不能充当真值或可信MPC模型。

沿用70:20、约90秒真实原始动态片段的现场测量链验证，至少10个时间点人工对照。该步骤不要求重新展开无界软件返工，也不替代长时间基线。原生ROI/无损帧保存、帧号和时间同步、标尺、芯片尺寸与液量边界沿用第一版要求。

优先使用可直接验证的液柱轴向长度；仅在深度及体积模型有依据时报告等效球径。所有阶段保持同一尺寸定义。相别以现场连接核对为准；频率混叠未解时不做高产率结论。

所有正向泵送设定值必须Q2>0、Q1>2Q2，并在命令量化及中间状态检查。当前Q1−Q2≥0.2的代码条件不等价于此约束；自动运行前须补齐检查。本方案不宣称已实现，也不把设定比当作芯片入口实际瞬时流量比。

## 4. 第一轮仅三个点，加不变流量对照

| 代号 | Q1 (µL/min) | Q2 (µL/min) | 比值 |
|---|---:|---:|---:|
| L | 60 | 20 | 3.0 |
| C | 70 | 20 | 3.5 |
| H | 80 | 20 | 4.0 |

已有记录出现过这些设定，但不视为已经完成物理标定。正式试验关闭会改流量的尺寸PID、前馈、BO，保留编排和安全停止。

| 区组 | 顺序；每格为一个观察段 |
|---|---|
| R1 | C基线 → C同值写入 → L → C → H → C → C同值写入 |
| R2 | C基线 → C同值写入 → H → C → L → C → C同值写入 |

每区组7段，其中4次真实阶跃、2次同值写入。两区组合计8次真实阶跃、4次同值写入。R2反转L/H顺序；后续独立重复可随机决定先执行哪个序列。两区组是初筛，不声称达到论文统计功效。

同值写入指走与真实阶跃相同的合法参数写入及回读路径，但目标值保持70:20；不启停电机、不执行清零/注射器配置等其他操作。如果程序优化掉相同值，必须记录“未发生实际写入”，不能算命令对照。设备协议不允许无扰动同值写入时仅做保持对照，并明确未隔离通信写入效应。

C基线与各段内选取的无命令时间窗提供自然漂移参照；同值写入对照检验命令路径影响，两者不能混称。60→70与80→70比较同一终点的历史影响；70→60与70→80提供相反方向响应。只有基准恢复到预先规定的允许范围才进入下一次真实阶跃，未恢复则记录状态并结束该区组，不能以“再等一个固定时长”自动放行。

## 5. 时间和液量预算

每段计划300秒；这个时间来自现有分钟级观察线索，是记录预算而非稳态结论。第一趟可以先完成R1前4段（20分钟，2次真实阶跃、1次同值写入），核对测量与回归基准后再决定是否完成其余段；不自动追加试验。

| 范围 | 计划驻留 | Q1命令积分 | Q2命令积分 |
|---|---:|---:|---:|
| R1前4段 | 20分钟 | 1.35mL | 0.40mL |
| 完整R1 | 35分钟 | 2.45mL | 0.70mL |
| 完整R1+R2 | 70分钟 | 4.90mL | 1.40mL |

以上均不含充液、预热、排气、90秒验证和切换额外耗液。两区组的补液/间隔应留记录，补液后重建基准。

若300秒末仍无可信参考段，有两种预先约定的执行版本：基础版结束并标“未确认”；延长版每段最多600秒，在事先填写的液量/行程/运行边界内延长。全部段达到600秒时，两区组上限140分钟、Q1=9.80mL、Q2=2.80mL，准备耗液仍另计。600秒也是预算上限，不是稳定保证。实验前选定版本，不在看到结果后无界延长或挑选某些方法单独延长。

同一幅面原始记录的数据量也随驻留翻倍，按90秒4.888GiB的旧条件估算，70分钟约228GiB；采用原生ROI/无损压缩并实测容量，不能以降低采样后仍假定频率可辨识。

## 6. 数据判读：先响应，再评价，最后排名

### 6.1 响应真实性和可重复性

持续采集覆盖命令前后，不允许调泵时暂停图像保存。对齐命令起始与回读完成，分别报告耗时。以无命令基线和同值写入对照估计噪声/漂移，再判断真实阶跃是否存在超出两者的持续变化。运动模糊、失焦、定位丢失、气泡和补液事件独立标记。

按5秒不重叠窗口绘制尺寸中心、散布、有效覆盖和过线事件数；窗口样本不足即无效。响应起点算法用第一趟数据摸底，后续冻结；不能用检测确认时刻代替最早变化。没有可分辨响应、或起点落入数据空档，报告无法辨识或区间。

若同值写入也产生明显尺寸变化，先检查命令路径；若所有段同方向漂移，先处理基线漂移；若70:20从低、高两侧返回后的末段持续不同，则不能直接假设“工艺结果只依赖当前Q1/Q2”。需检验是否观察不够长、真实滞后或批次变化，再决定是否使用带历史状态的模型。

### 6.2 定义可靠评价时间

令m(t)为在t时刻结束的过去30秒内、独立液滴尺寸的均值，m_ref为合格末段参考均值，计算e(t)=|m(t)−m_ref|/m_ref。长度和等效直径不能混用。稳态趋势可用每秒中心统计，但CV必须由独立液滴样本计算，不用秒均值的CV替代液滴CV。

选择评价容差epsilon_eval：从工艺允许误差中分配，并高于测量可分辨尺度。例如工艺尺寸容差±5%，可先提出评价偏差不超过1%–2%；只是设计示例，若测量不确定度已大于该范围，则该方案不能验证这一精度。首次摸底后冻结容差和窗口，后续验证不再调参。

参考段为至少120秒有效尾段，检查两个相邻60秒子段中心差、趋势、分布和数据质量是否满足预先定义的参考要求；末尾仍持续漂移或失效则无参考。不用“最后一段”自动代表物理稳态。额外延长段保留原300秒时刻，便于检验原参考是否仍偏差过大。

探索性离线可靠评价时间：e(t)达到容差并在随后预定60秒内保持，且后续可见记录无超差的最早窗口结束时刻。它使用未来参考，属于有限观察范围内的事后标签，不是可在线直接计算的决策时间，也不保证永久稳定。

在线候选策略只能使用当前和过去的趋势、相邻窗口差异及样本不确定度，预测当前评价是否足够可靠。先用原120秒工程判据作兼容对照，不强制新策略也等待140秒。算法在预实验后设计并用新的独立区组验证，不在同一批数据上调到完美后宣称在线有效。

### 6.3 排名与选点作为下一层验证

先展示30、60、120、180秒的评价偏差，再判断L、C、H或后续更广参数点能否区分。使用共同70:20起点比较L/H，基准漂移单独报告。若效果接近而置信区间重叠，报告无法区分，不强造排名反转。

工艺目标在独立验证前确定，可依据应用需求或独立摸底选择可达目标，但不得依据验证集哪个目标能制造翻转来选择。主要指标为合格误判、选中点最终误差和时间成本；参数排名翻转只是辅助机制证据。

逐帧记录、同一滴重复图像、重叠时间窗均不作为独立重复。两区组只给原始轨迹和探索性差异；正式置信区间采用独立区组，区组内时间相关可用连续片段重采样，不能按所有帧随机重采样产生虚假精度。

## 7. 什么结果支持继续

| 结果 | 下一步 |
|---|---|
| 真实阶跃响应超过保持/同值对照，早期评价偏差重复出现，可靠评价时间随方向/幅度改变 | 扩展50/90与Q2，研究暂态感知优化 |
| 响应清楚，但各条件可靠评价时间接近且保守固定等待代价很小 | 保留固定等待，不把自适应等待强作创新 |
| 返回相同点的参考值持续依赖前一状态 | 优先区分长暂态、滞后与批次漂移；考虑历史状态建模 |
| 测量误差或自然漂移与阶跃效应同量级 | 先改善测量/过程可重复性，暂不扩大参数网格 |

第一版的四轮宽范围Q1扫描及Q2/等比例/等总流量实验作为备选扩展，依据上述结果选择，不默认全部完成。

## 8. 工艺优化与论文主张的边界

当前任务是为工艺优化建立可信评价，不能由阶跃曲线直接称完成工艺优化。后续先选目标尺寸与质量约束，再搜索Q1/Q2；MPC是可选的后续控制方向，优化器不必等待一个完美MPC模型才能研究。

高产率目标需要可验证频率与双输入设计。稳态无存储、无合并分裂/泄漏且所计液滴覆盖全部分散相时，f×平均滴体积=实际分散相流量；固定分散相流量及滴体积时，频率并非独立自由变量。因此固定Q2扫描不能直接证明“同尺寸下产率最优”，相别和物理流量还须核实。此守恒关系见原始研究： https://www.tandfonline.com/doi/pdf/10.1080/19942060.2023.2243091 。

论文候选主线：在带过渡过程与历史影响的微流控实验中，联合选择下一组工艺参数和评价时机。算法贡献必须超过一个可调等待按钮；可从评价偏差/不确定度估计入手，在公平实际时间与耗液预算下比较固定等待BO、自适应等待BO及带切换耗时决策的方法。基线固定等待也应由独立摸底合理整定，不能故意取过长值。

只有前瞻、独立批次验证显示优势，才主张提高优化效率。两区组预实验不构成二区水平证明，不预设百分比提升或保证录用。
