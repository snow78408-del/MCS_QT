# 原液滴识别算法直接优化（2026-10-22）

本轮由 Codex 直接修改代码，保留管壁注册→透视扶正→原相位规则→完整性/尺寸历史→跟踪统计的流程。没有新增模型训练或把独立网络替换为主检测器，没有连接相机、泵或提交 Git。

## 实现

- `capsule_profile.py`：没有载液相位分隔的内部峰合并为一个种子，保留较强峰；端点扫描改为 NumPy 查找。
- 原 0.02 支撑、局部载液、曲率、长度和边缘守卫通过后，使用 0.03 支撑小幅收紧光学尾部。每端最多移动 0.25 倍通道跨度，收紧后仍检查载液曲率及最小长度。显式更强的支撑（例如 0.10）不受该收紧影响。新增函数参数 `endpoint_support_fraction`，诊断记录其值。
- `detector.py` / `pipeline.py`：标定相位模式请求紧凑诊断时，不计算不参与该模式判定的增强图、中心梯度和轮廓诊断。直接 `detect()` 默认仍保留完整诊断，调参界面保持原接口；关闭诊断时相关数组为 None，不能冒充已计算。
- 学习模型的有界建议仅记录在 `phase_diagnostics.learned_endpoint_refinement`，不修改主候选、尺寸历史、有效测量及跟踪输入。传入图像和候选副本，防止插件原地修改。

## 参数选择与精度

使用原 54/16/12 划分，只以 train/val 比较候选改法。直接提高原候选阈值到 0.03/0.05 会增加误检，因此未采用；在守卫通过后有界收紧，0.03 优于 0.05。选定后再运行既有 test。该 test 已被历次工作重复评分，是回归集，不是新的盲测。

原图笔迹通过同一透视变换映射到条带；沿用一对一 IoU≥0.5 匹配，未标注外部区域不计负例。误差单位为真实条带像素，不是 0–719 归一化坐标。下表使用新旧共同匹配集合：
