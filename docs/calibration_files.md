# 自动标定的三个文件

这里指运行监控里的“泵—芯片动力学标定”，与相机像素比例标定不同。

例如在保存窗口中选择 `plant_calibration.json`，程序会在同一目录生成：

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `plant_calibration.json` | 基准流量与尺寸、Q1/Q2 灵敏度、响应延迟、时间常数、控制参数、局部流量范围和验证结论 | 在基础参数页加载，供控制器使用 |
| `plant_calibration.measurements.json` | 实验配置、各回合基线及阶跃测量、响应曲线与时间信息、拟合结果 | 复核标定过程，评估后续 MPC 建模数据 |
| `plant_calibration.mpc-training.json` | 原始动态曲线、流量、时间、工况、单位及独立训练/验证分组 | 用于后续 MPC 模型建造；记录当前模型是否通过验证，不等于部署授权 |

配套文件自动按主文件名追加 `.measurements` 和 `.mpc-training`，不用单独导出。
三份来自同一次实验，使用一致的 `calibration_id`。

每次按已确认次数执行一轮，包含独立验证，不自动追加试验或延长等待。PID 验证
通过即可保存并选入控制参数，同时导出 MPC 建模数据；当前 MPC 拟合未通过不阻止
PID 使用。响应不足或 PID 验证未通过则停泵并保留诊断，不能强行生成可加载参数。

## 如何获得

1. 完成相机测试取帧、生成区 ROI 和物理尺寸/比例配置，确认识别正常。
2. 完成泵识别及 Q1/Q2 参数写入回读。
3. 进入“运行监控”，点击“打开标定窗口”，填写装置、流体、通道尺寸、阶跃幅度、基线等待等参数。
4. 点击“运行标定”。程序实际执行小幅阶跃、采集液滴数据，并做独立验证；运行时会调节真实泵。
5. 完成后选择保存位置。若取消了保存对话框，可在标定窗口中点击“保存标定结果”。
6. “标定文件已保存”提示会列出三份文件的完整路径，主文件路径也会填入基础参数页。

用于检查实际系统的应是设备实验保存的文件，项目测试生成的模拟 JSON 不代表设备已标定。实验失败或中止不会得到可当作成功标定使用的结果。

默认使用非线性二次响应面与动态曲线辨识。PID 未获授权时也会自动归档
不可作为闭环标定加载的 MPC 建模数据，保留实际采集完成标记及拟合失败原因。
模型形式、局部 PID 范围及论文适用边界见 `nonlinear_calibration.md`。

## 检查 MPC 数据时看什么

先核对主文件与原始测量是否配套、装置/流体/工作点是否匹配，再检查原始阶跃曲线、时间戳、拟合误差、独立验证误差以及两路响应是否可分辨。`validated_for_mpc` 只表示通过当前数据筛选条件，不表示 MPC 控制器已经实现或经过闭环验证。

## 前馈使用

在“基础参数”的“前馈独立设置”中选择目标前馈，保存并重新初始化。它使用主文件中的已验证局部模型估算目标尺寸需要的流量修正，与 PI 共用原限幅和调泵事务；目标超出模型可达范围时不启用该修正。运行中可通过“更改目标”测试目标变化。

扰动前馈是另一个独立选项。当前生成区控制尚没有与对数尺寸输出单位匹配的扰动前馈标定，因此即使勾选也保持阻断；自动标定主文件不能代替这项验证。监控 PID 详情会显示具体原因。

## 用历史记录复核模型

多次标定（含失败或被中止的记录）可以汇总复核：`tools/fit_plant_history_model.py`
把所有历史会话的试验放在一起，比较常数、线性、二次响应面、对数与幂律等候选形式，
用留一会话交叉验证排序，并输出模型系数、会话聚类置信区间、诊断表与图片。
该工具只读历史目录，不生成可加载标定；结论与用法见 `plant_model_history_fit.md`。
