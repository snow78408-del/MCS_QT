# 液滴工艺优化预实验统一方案

日期：2026-09-22。状态：实验设计，未执行实体操作。本方案整合近期实验、历史模型复核及离线阶段验收；不代表当前装置已就绪。

> 后续复审：本文件保留为第一版。当前推荐次序以 [第二版：最小判别实验](process_optimization_experiment_plan_v2_20260922.md) 为准。先用不变流量对照与顺序反转区分响应、漂移及历史效应，再决定是否执行本文件的广范围扫描。不能把第一版的100/250分钟与第二版预算相加后直接执行。

## 1. 研究目标与当前依据

回答：不同参数切换需要多久开始响应、多久获得可靠工艺评价；提前评价是否改变参数选择；自适应等待能否在保持评价可靠性时节省实验时间。

依据：
- `deepseek_measurement_audit_plan_20260921.md`：旧实验约5.3秒是指令至回读耗时，且有采样空档；约200秒为带180秒最早检查门槛的离线确认结果，不能当作物理响应时间。
- `plant_model_revision_20260919.md`：旧速度混叠未解，标尺及几何存在条件假设；不能采用固定30–35秒、10分钟或16倍流量修正结论。
- `deepseek_next_stage_plan_20260922.md`：70:20短时验证、四轮基准往返、120秒工程窗口及模型独立验证要求。
- `offline_stage_acceptance_20260922.md`：有限离线回放、原始帧保存及稳态窗口计算阶段通过；真实动态测量、相机有限等待和设备停止仍待现场验证。81项测试为该验收实际复跑，890项为实施方完整套件自报，本方案没有重新测试。

不假定Q1/Q2的相别已经由现场核对。软件注释的相别映射不能替代管路确认。全程先使用通道名称Q1、Q2。

## 2. 硬约束和执行前提

所有下发点满足Q2>0且Q1>2Q2，单位统一为µL/min。检查设备量化后的实际命令数值；严格不等式不使用近似相等放行。遵守已验证设备范围和步长。

当前`backend/pump_hardware/invariants.py`检查Q1至少比Q2大0.2，不等价于Q1/Q2>2。实体自动运行前需在实验计划验证和下发路径补充比例检查与边界回归；本次只出方案，未修改这些实现。双通道顺序写入还须检查中间组合。对物理瞬时流量比不作仅凭设定值的保证。

PID、前馈、BO不同时修正实验流量；编排器独占命令通道，现有停机保护保留。不得复用带顶层设备操作的旧长驻留脚本。

现场记录芯片/管路、Q1/Q2连接、注射器及泵配置、标尺、深度来源、液量、行程、存储、相机设置及停止边界。补液、换芯片、改视野后新建批次并重建基准。

## 3. 阶段A：70:20真实动态测量验证

液路充满、画面可见后，以70:20记录90秒原始动态片段。排气另记。90秒是测量链验证长度，不是稳态等待结论。

保存原始像素、硬件帧号、采集时间及其来源、图像变换和拒绝原因。至少抽取10个分散时间点，对照原图、管壁、液柱两端与测量值；增加起止和难例，避免只选成功帧。

独立标尺未完成时只能输出像素诊断；已有标尺但深度未知时可报告轴向长度，不能报告可信体积等效球径。后续研究选择一种尺寸定义并固定，不能把液柱长度与等效直径混用。

通过条件：测量区域完整；真实动态边界可人工复核；原图和尺寸逐帧对应；尺寸单位有依据；时间单调且缺口有记录；来源可有限等待、取消和释放；设备异常停止路径已核对。人工对照误差需小于拟研究的尺寸差异，具体容差在正式实验前记录。

原计划100Hz、90秒约4.888GiB为条件预算，不是实测吞吐。按相同画幅100分钟约326GiB，长实验前必须根据实测写盘速度和容量重新预算，可采用保留完整检测区域的原生ROI或无损压缩；不能静默丢帧。无法解决频率混叠时不以频率作为优化目标。

## 4. 阶段B：固定Q2的核心实验

沿用既有四轮，避免另起不一致的24阶跃方案。每行独立区组，初始70:20单独建立基线；每个箭头才算一次阶跃。

| 区组 | 顺序（Q1:Q2） | 计划时长 | Q1预算 | Q2预算 |
|---|---|---:|---:|---:|
| B1 | 70:20 → 50:20 → 70:20 → 80:20 → 70:20 | 25分钟 | 1.70mL | 0.50mL |
| B2 | 70:20 → 60:20 → 70:20 → 90:20 → 70:20 | 25分钟 | 1.80mL | 0.50mL |
| B3 | 70:20 → 90:20 → 70:20 → 60:20 → 70:20 | 25分钟 | 1.80mL | 0.50mL |
| B4 | 70:20 → 80:20 → 70:20 → 50:20 → 70:20 | 25分钟 | 1.70mL | 0.50mL |

合计20段、16次阶跃、100分钟；Q1约7.00mL、Q2约2.00mL。比值2.5–4.5。预算仅为设定值积分，不是物理流量实测；准备、切换、排气、延长、残余不可用液量另计。四个外围点各进入两次，返回70:20共8次。两次重复仅供筛查，论文阶段根据方差增加独立重复。

每段计划300秒。基线不稳定不开始下一阶跃；末段未稳定标未确认，不以时间到自动认证。需延长时在执行前明确每段上限及额外液量；本基础版本300秒到仍未恢复基准则结束本区组，不自动追加轮次。

采集先于指令开始，指令下发和回读期间持续采集。记录command_started、各通道write、readback_completed、response_onset_candidate、first_confirmation和final_stable_interval。

## 5. 三种时间分开计算

### 开始变化时间

用阶跃前至少60秒有效基线估计自然波动，对阶跃后5秒非重叠窗口中心值检测持续偏移。摸底候选阈值为基线窗口波动尺度的3倍与测量分辨能力中的较大者，连续3窗同向偏移才确认；阈值先用基线中的虚拟切换点检查误报，再冻结。最早异常窗为起点候选，第三窗结束是检测确认时刻，两者分列。小响应或采样空档下输出无法辨识/区间，不填0。

### 在线工程稳态确认

保留近期配置：120秒窗口、每10秒检查、连续3次通过，中心趋势斜率绝对值≤0.1µm/s；每窗只用当时已经获得的数据。该单位阈值仅适用于已校准且一致的尺寸定义，像素诊断不能照搬。

覆盖率0.6、最大空档15秒、最新有效样本距窗口末端≤5秒为现有工程配置，不是测量精度保证；缺口覆盖响应起点时仍不可辨识起点。质量分布单独报告，不回退到旧的斜率0.01且分布宽度≤2的判据。用户接受过−0.073µm/s的小漂移，不等于已经规定所有工况的通用阈值。

完整阶跃后窗口最早120秒形成，三次确认最早140秒；此下限是算法造成的。去掉旧180秒最早检查门槛，报告首次确认、重新失稳、末端状态和最终再确认。

### 末段参考与离线稳定区间

参考数据使用末尾120秒，分成两个60秒段核对趋势与中心差异；只在有效覆盖、无失效事件、无持续漂移且差异处于预先定义的工艺容差内时接受。正式容差由阶段A测量精度和目标工艺要求共同固定。拒绝参考的试验保留为未确认，不能用于“真实排名”。

回溯进入参考容差带并持续保持的区间可以作为离线稳定区间，必须标注使用了未来数据；不得作为在线决策时间。CV或p10–p90单独报告：分布较宽但中心不漂移可判趋势稳定，仍可能工艺质量不合格。

## 6. 过早评价与参数优劣

在阶跃后30、60、120、180秒，分别用其之前30秒评价。只使用当时可见数据；与末段180–300秒参考区间不重叠。240秒评价可作附录敏感性分析，注明与参考数据重叠，不作为主要独立比较。

阶段A后、正式B实验前固定一个尺寸目标及容差，不用B结果事后挑选最容易显示优势的目标。频率尚未验证时，先以目标尺寸误差排名，CV和无效比例分开报告；不能宣称已经优化产率。频率可靠后再采用“尺寸/CV合格前提下最大生成频率”。

仅比较相同起点70:20进入50、60、80、90的试验；跨区组同时报告基准变化，不强行混合补液前后数据。返回基准用于历史效应和漂移分析。工艺差异小于不确定度时判并列，不强排行。

输出：尺寸误差偏差、合格误判/漏判、共同可行点的成对排名翻转、所选点最终损失，以及未能评价比例。失败/缺失不当成0误差。统计单位为独立阶跃/区组，不是帧数或液滴总数。

自适应策略模拟：当在线判据确认后，额外取30秒独立评价窗口；时刻不足或超时即未完成。与固定等待策略比较“等待＋评价”总用时和错误率。本阶段只是同一批数据上的离线决策回放；正式提速结论需要后续实际提前结束的前瞻实验。

## 7. 阶段C：分离Q2、比例与总流量影响

只有B和测量链可用后安排。新增点为候选，需确认有效成滴与装置范围，不视为已运行证据。

| 目的 | 顺序 | 每轮预算（每段5分钟） |
|---|---|---|
| 固定Q1，改变Q2 | 70:20 → 70:15 → 70:20 → 70:25 → 70:20 | 25分钟；Q1=1.75mL，Q2=0.50mL |
| 固定比例3.5，改变总流量 | 70:20 → 56:16 → 70:20 → 84:24 → 70:20 | 25分钟；Q1=1.75mL，Q2=0.50mL |
| 固定总流量90，改变比例 | 70:20 → 65:25 → 70:20 → 75:15 → 70:20 | 25分钟；Q1=1.75mL，Q2=0.50mL |

每类先做正序与反序两轮，共150分钟、Q1=10.50mL、Q2=3.00mL，另计准备和延长。与B合计250分钟不是一次连续运行要求，应按批次拆分。此设计覆盖比例与总流量的局部效应，仍不足以宣称完整二维全局最优。

双通道切换先验证(Q1新,Q2旧)或(Q1旧,Q2新)中间点，选合法顺序并记录间隔；控制实际瞬时比值需两路物理响应证据。

## 8. 模型、论文推进与交付

先比较无响应常数模型与局部带延迟一阶模型，发现明显非单调/漂移时再比较更复杂结构。前两区组用于初拟合，后两区组先保留验证；数据不足时增加重复，不能用验证集反复调模型后仍称独立验证。报告参数区间、残差、边界命中和验证误差，不可辨识时留空，不写入MPC。

拟研究主线：稳态感知与实验耗时驱动的约束工艺优化。当前预实验只证明问题与方法可行性，不保证二区录用。若早期排序变化和等待差异明显，再比较固定等待BO、自适应等待BO、自适应等待加耗时建模BO；公平计入初始化、切换、失败、等待和评价时间，最终进行跨批次前瞻验证。

每次交付原始帧清单、命令事件、尺寸/频率及质量序列、阶段摘要、评价表、拒绝原因和版本/标定信息。主要图：阶跃响应及时间标记、稳定时间散点、早期与参考排名、时间—评价可靠性、返回基准漂移。原始数据不覆盖，派生结果单独保存。
